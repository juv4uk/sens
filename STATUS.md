# SENS — стан виконання (21.10.2026)

Це **коротка карта роботи**, а не окремий семантичний контракт і не автоматична декларація зеленого CI. Чинна влада: [`CURRENT.md`](CURRENT.md), [`language-contract.lisp`](language-contract.lisp), [`lib/domains/`](lib/domains/). Поточні результати визначати за точним SHA й реальним виконанням.

## Уже є у main

- Ратифіковані D1–D10 (D10 як каталог 1024/1024; його resident callability та фізичне виконання не випливають із заповненості таблиці). D7 v2 — клавіатурні дані; D11 — **43 нератифіковані тестові позначення**, що потребують перевірки й коректного розміщення; вони не є викличним Core.
- Українські людські викличні імена беруться з повної колонки `укр`. [`source_projection.rs`](crates/sens/src/source_projection.rs) переводить звичайні знакові десяткові **цілі** в exact D24+ для явно українських точок входу; у зв'язаному D5 математичному дереві ширина узгоджується.
- `.sens` — фізичне T5M-подання; `.lisp` — людська поверхня. Однойменний файл без розширення — похідний перегляд exact-bit слів, не третя мова. Zig — механічний транспортний коридор, не джерело законів.
- Центральний [CI](.github/workflows/ci.yml) використовує GitHub-hosted Ubuntu 24.04. У чинному файлі **немає** блока `concurrency`, ані `cancel-in-progress`, ані `queue: max`; тому не можна приписувати йому гарантоване збереження запусків чи чергу на 100 місць. Фактичний стан кожного workflow визначається GitHub Actions для його точного SHA.

## Реліз l0.42.0 та оберненість джерел

**NO-GO (21.10.2026):** точний SHA кандидата не закріплено, актуальне
зелене виконання SENS на ньому не засвідчено, усі фізичні T5M-трійки
та незалежні українські oracle-свідки не прийняті. Жодного тега й
публікації до власницького GO.

Інструменти розрізняють три твердження, які заборонено змішувати:
механічний облік кожного `.lisp` у Git; фізичний побайтовий
`.sens → біти → .sens` круговий перехід; доведене
`.lisp(укр) ↔ точні слова ↔ .sens` разом із виконанням SENS.
Повний третій рівень **не підтверджено**.

- `scripts/migration-readiness-census.py` робить один AUTO-прохід,
  без публікації фізичних файлів, і окремо повідомляє NO-GO.
- `scripts/report_t5m_migration_progress.py --require-executable-roundtrip`
  відмовляє без повного незалежного SENS-доказу кожної виконуваної програми;
  архівні DATA не записуються як executable.
- `scripts/release_go_gate.py --structural-only` дозволяє
  лише структурним guard-ам пройти в релізному preflight.
  Типовий запуск більше не плутає такий PASS із готовністю до публікації.
- Звіти GitHub Actions мають відображати кількість блокованих або
  неперевірених програм, а не уявні 100% міграції.

## Вимагає конкретного доказу / наступного виправлення

- Повні дробові десяткові літерали, інші типи чисел поза підтриманим source-проєктором, та всі шляхи, які ще обминають потрібну exact-domain/transport межу.
- Повна, пофайлова міграція активного `*.lisp` на `укр`, історичних SID8/Sens8 викликів і відповідних фізичних T5M-пар; автоматичний бітовий roundtrip не замінює семантичного oracle.
- Доведений фізичний runtime admission окремих функцій (особливо D10), перевірка фактичного актуального CI/логів, а не повторне оголошення старих PASS/FAIL.

**Робочий принцип:** маленьке виправлення → реальний SENS-виклик і позитивний/негативний свідок → потрібне вимірювання; локальний дефект не заморожує весь проєкт.
