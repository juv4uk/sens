# Чотири програми SENS, мігровані у два представлення

Джерело — чотири вихідні форми в `tests/fixtures/canonical-binary-smoke.lisp`; Git blob: `58345fe07bb0023202c20354249a7047bf098ab6`.

Кожна програма має три файли того самого stem:

- `smoke-*.lisp` — канонічна українська `ук` поверхня;
- `smoke-*` — ті самі точні двійкові слова із пробілами та кінцевим LF;
- `smoke-*.sens` — наявний фізичний запис T5.

Фізичні файли `smoke-*.sens` уже збережено поруч із читаними проєкціями. Їхня наявність не є доказом канонічної української зворотності для всього корпусу чи SENS-виконання. Міграція цих чотирьох форм не рахується автоматичним семантичним або релізним допуском.

Контроль: `python3 -m unittest discover -s tests -p 'test_migrated_two_projections.py' -v`. Порівнюються з початковою двійковою програмою, чинним українським рендерером і зворотним проєктуванням точних слів.

Збережені `.sens` перевіряти поточним фізичним декодером та незалежним SENS-свідком; одного побайтового збігу з `smoke-*` недостатньо для релізу.
