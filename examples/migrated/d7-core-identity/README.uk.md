# Точкова міграція Lisp → SENS з D7 (три фізичні файли)

Вихідна форма: **перше виконуване визначення** з `lib/core.lisp`, відтворене буквально у `source.lisp`. Цей доказ не означає міграції всього великого `lib/core.lisp`.

```lisp
(0011 identity (0010 (value) value))
```

Канонічна машинна структура: D4 DEFINE=`0011`, D4 LAMBDA=`0010`, D2 OPEN/SEP/CLOSE, W7-рамки імен `identity` та `value`. Ім'я/змінна — не текстова команда й не SID8. Кожний ASCII-символ імені став точною координатою D7 v2.

Результати `identity.uk.sens`, `identity.en.sens`, `identity.san.sens` — **ті самі фізичні T5 байти**: мовна проєкція не впливає на виконуваний код. `identity.bits` — видимий доказ точних слів (51 слово; 196 значущих бітів без структурного T5 framing; 50 байтів T5). `source.lisp` — свідчення вихідної форми, не джерело для виконання замість машинного коду.

Машинні файли декодуються через існуючий `scripts/sens_t5_codec.py`. Тест: `python3 -m unittest discover -s tests -p 'test_d7_core_identity_triplet.py' -v`.

Обмеження: T5 round-trip і структурні D2/D4/D7 перевірки ≠ виконання інтерпретатором; runtime parity ще не доведено. Оригінальний `lib/core.lisp` не змінено. Це початкова точкова міграція однієї **форми**, не всього модуля.
