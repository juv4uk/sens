# Історичний приклад D7 v2 — одна фізична програма

Це історичний навчальний корпус точних слів D2/D4/D7. Він **не є** доказом сучасного T5M-допуску, семантичної зворотності українського Lisp або готовності до релізу.

Людський приклад у `source.lisp` зберігає походження старої форми:

```lisp
(визначити identity (функція (value) value))
```

Поточна українська програма повинна використовувати повні чинні імена з `укр`; механічне історичне кодування ASCII-імен `identity` та `value` не підмінює її. До справжньої української міграції цей приклад має статус **історичний, семантичне виконання не сертифіковано**.

Побайтово ідентичні копії `identity.uk.sens`, `identity.en.sens`, `identity.san.sens` вилучено: поверхні мов не створюють окремих двійкових програм. Лишається **один** фізичний файл `source.sens` та його `source` — видимий бітовий перегляд. `identity.bits` — історичний контрольний зразок тих самих слів.

`source.sens` і контрольні слова порівнює `tests/test_d7_core_identity_triplet.py` як **структурне дослідження**. Використаний цим тестом історичний Python T5 кодек — лише контроль побайтової спадщини, а не дозволений виробник сучасного `.sens`. Він **не** є незалежним SENS-evaluator або Zig/T5M. Для релізу обов'язкові окремі Zig T5M, зворотна українська проєкція та реальне позитивне й негативне SENS-виконання.
