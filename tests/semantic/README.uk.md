# Закони мови SENS — тести мовою Lisp

Цей каталог містить виконувані мовні свідки. Нові семантичні та логічні твердження записуються без цифрових голів і літералів, українськими іменами чинної драбини. Пара `*-law.lisp` і `*-mutant.lisp` повинна повертати відповідно точний D1:1 та D1:0 у **справжньому** SENS.

Перший набір: `d1-not` — однобітне заперечення; `d2-cond-laziness` — вибір гілки та відсутність виконання невибраних гілок; `d3-structure` — структурні закони цитування, сполучення, селекторів і тотожності. Ці свідки не оголошують повне покриття D1–D3.

Запуск після складання `sens`:

```sh
bash scripts/prove-lisp-language-laws.sh target/debug/sens
```

Скрипт не реалізує семантику: лише запускає шість .lisp, перевіряє код завершення й рівність однобітного виводу. Наявні Rust-тести механізму та Zig-тести транспорту залишаються в їхніх мовах. Старі Rust-оракули семантики мігрують поетапно, лише після підтвердженого виконання Lisp-свідків. Фізичний T5M-коридор і незалежна оберненість підтверджуються окремо; PASS джерела сам по собі не є релізним допуском.

## Додаткова сім'я: рекурсія над списком

`d5-recursive-list-law.lisp` перевіряє функцію `визначити`/`функція`, базовий випадок порожнього списку, рекурсію через `решта`, атомність `перше` та відхилення вкладеної пари. `d5-recursive-list-mutant.lisp` змінює саме рекурсивну умову; очікується D1:0. Обидва тести проходять `--t5m-mint`, `sens-trit open`, `verify-view` та `--t5m-pair` у `scripts/prove-lisp-language-laws.sh`. Семантичний вердикт належить SENS, не Rust або Zig.
