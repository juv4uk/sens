# Ратифіковані доменні координати: виконуваний двійковий SENS

Тут **тільки машинні програми SENS**: `proof.bits` — слова 0/1 із точними ширинами, `proof.sens` — фізичний T5. `mutant.bits` і `mutant.sens` — SENS-програма з навмисно хибним законом EQ; виконання **мусить аварійно завершитися** через не-викличний D1:0 у гілці COND.

- Координати: 1018 = D1:2 + D3:8 + D4:16 + D5:32 + D6:64 + D7:128 + D8:256 + D9:512.
- 1018 законів `EQ(QUOTE x, QUOTE x)` і 1018 законів `EQ(QUOTE x, QUOTE (x XOR 1))`.
- Ще 4 закони D3: ATOM порожнього, ATOM пари, CAR(CONS 1 0), CDR(CONS 1 0).
- Разом **2040 перевірок**, розподілених на 85 незалежних послідовних виконуваних форм, не глибше 24 вкладених контрольних кроків.
- Умови, очікувані істинні/хибні значення та аварійний шлях **вписані всередині SENS**, не в Rust/Python. Host CI лише запускає фізичний файл і перевіряє статус та паритет двох точок входу.
- 77 599 слів, 191 944 значущі біти, 53 909 байтів фізичного T5. Структурні D2 00/01/10/11 не вважаються функціями. D10 і D24+ не допущені цим тестом.
- **Це не доказ, що всі 1018 координат виконуються як callable.** Викликаються D3 EQ, QUOTE, COND та базові CAR/CDR/CONS/ATOM; решта — точнодоменні дані. Історичний SID8 не отримує жодного нового права виклику.

Історичний `scripts/check-domain-logic-laws.lisp` залишається переліком ще не перенесених D5/IO законів, але чинні результати D1–D9 перевіряє двійковий SENS. Статус останніх законів не приховувати.
