# Дослід T21 / T22 / T33: фізичні носії без зміни семантики

**Статус:** дослідження, без ратифікації. Канонічний фізичний файл .sens залишається T5. Цей файл не створює доменів чи законів.

## Математика

Тритовий алфавіт 0,1,2; заборонено сусідню пару 22.
Кількість рядків: f(0)=1, f(1)=3, f(n)=2*f(n-1)+2*f(n-2).

| Носій | Тритів | Кількість рядків | Байти |
|---|---:|---:|---:|
| T21 | 21 | 1 579 869 184 | 4 |
| T22 | 22 | 4 316 282 880 | 4 або 5 |
| T33 | 33 | 273 203 580 829 696 | 6 |

Ранжування лексикографічне за кількістю допустимих продовжень у двостановому автоматі «останній трит був / не був 2». Числовий ранг — транспортний, не семантичний.

## Точний носій T22

U=2^32; K=ceil((f(22)-U)/255)=83591; D=U-K=4294883705.

* Якщо ранг r < D, записати 4 big-endian байти u32(r).
* Інакше записати 4 big-endian байти u32(D + (r-D)//256), потім один байт (r-D)%256.
* Декодер визначає за першими чотирма байтами, чи потрібен п'ятий.
* Надлишковий байт, обрізання, невикористаний ранг, пара 22 на стику блоків — помилка.
* За рівномірного розподілу допустимих блоків розширення трапляється приблизно в 0,49578% випадків. Для реальних програм ця частка не гарантована.
* Резерв розширення НЕ є безкоштовним полем режиму або CRC32.

## Межі

1. Підтримано лише повні блоки довжиною 21, 22 або 33 трити. Довжина, вибір схеми, версія, EOF, хвіст і CRC повинні бути задані в окремому конверті, якого цей експеримент не реалізує.
2. Кодер відхиляє 22 навіть на межі блоків; декодер перевіряє canonical decode→encode і відсутність зайвих байтів.
3. Це Python-кодек, не виконання SENS, не CPU-native/GPU/FPGA benchmark і не дозвіл переписати .sens.
4. Жодних нових GitHub Actions workflow — використовувати наявні bench-доріжки після перегляду й допуску.
5. Залежні роботи: issue #5294 (чесні бенчмарки), #5315 (потоковий конверт), PR #5311 (незалежна коротка рамка-3). Їхні файли не змінюємо.

## Відтворення

- Перевірка: python3 benchmarks/byte-pack/носій22.py --verify
- Вимір: python3 benchmarks/byte-pack/носій22.py --bench --ntrits 4620 --reps 15 --out /tmp/t22-results.json

Контрольний корпус: 4620 однакових логічних тритів для всіх схем, зерно 20261010. Зафіксовані розміри 880 / 840 / 840 байтів (T21/T22/T33). JSON містить сирі часові виміри, середовище й SHA256 тритової послідовності; часи Python не переносити на GPU або VM.
