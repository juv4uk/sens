# human-wire-arq (#2646)

Zero-dependency Rust benchmark: block framing, CRC16, sync resync, optional Hamming(7,4)
and selective retry for a human-keyed binary wire. Mechanism only; no semantic authority.

Run: `cargo test && cargo run --release`.

Українською: нульові залежності; блокове кадрування, CRC16, ресинхронізація за SYNC,
необов'язковий Хеммінг(7,4) і вибіркова повторна передача для бінарного каналу, який
вводить людина. Лише механізм транспорту, без семантичної влади.
