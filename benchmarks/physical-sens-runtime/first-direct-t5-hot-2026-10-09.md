## Межа висновку

Фаза **t5_open_d2** перевіряє D2 і створює людиночитну текстову проєкцію. Фаза **t5_direct_d2** декодує трити в точні доменні слова та розбирає D2 через щільний payload без тексту. Їхня різниця — вартість двох різних API-маршрутів, **не** прискорення всієї програми, не чистий час обчислення й не перевага SENS над Python. Паритет цих маршрутів сам по собі не є незалежним семантичним оракулом.

Більша частина переваги прямого T5-маршруту в цьому корпусі з'являється до ізольованого D2-парсера, за рахунок відмови від текстової проєкції та зайвої роботи.

Відтворення в корені репозиторію:

    cargo build --locked --release -p sens-cli --bin sens --bin sens-trit
    cargo build --locked --release -p sens --example physical_sens_hot_bench
    python3 benchmarks/physical-sens-runtime/hot.py --binary target/release/examples/physical_sens_hot_bench --sizes 1,16,128,1024 --samples 11 --work-budget 65536 --out /tmp/sens-physical-bench

Сирі файли hot-raw.tsv, hot-results.json, hot-environment.json і hot-report.md збережено в артефакті зазначеного GitHub Actions run (обмежений термін зберігання).
