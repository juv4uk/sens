# Конкурс бенчмарків за сферами

**ЦІЛЬ:** D6 `додати-1` — `lib/domains/d6.lisp:23`, код `001110`, LISP `ADD1`.
**Властивість:** для точного D24-цілого `n` результат дорівнює `n + 1`; переповнення немає.

## Розподіл сфер

| мова | сфера | що міряє |
|---|---|---|
| **SENS** | семантика і логіка | правильність `додати-1` над D24, час одного семантичного кроку |
| **Zig** | корідор | перенесення T5M: кодування й декодування числа без втрат |
| **Rust** | механізм | розбір десяткового запису в точне ціле, введення-виведення |

Кожна мова міряє лише свою сферу. Чужа сфера — не її бенчмарк.
