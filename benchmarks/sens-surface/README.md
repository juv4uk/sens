# Бенчмарк поверхонь sens (#1413, вісь A)

Порівнює **одну й ту саму програму** в чотирьох поверхнях мови sens:
англійські імена (`en`), голі SENS-коди (`sens`), українські імена (`uk`)
і англійські імена з примітивами, обгорнутими написаними Lisp-функціями
(`wrap`, стиль більшості `lib/*.lisp`, див. #1277). Усі чотири форми
генеруються з одного шаблону в `run.py`; різниться лише написання
примітивів, імена користувацьких функцій однакові.

## Запуск

Лише через Guix-профіль репозиторію (`channels.scm` + `manifest.scm`):

```bash
guix time-machine -C channels.scm -- shell -m manifest.scm -- \
  env CARGO_TARGET_DIR=target-guix cargo build --release -p my-lisp-cli --bin sens --offline
guix time-machine -C channels.scm -- shell -m manifest.scm \
  -m benchmarks/sens-surface/manifest.scm -- \
  python3 benchmarks/sens-surface/run.py --sens target-guix/release/sens
```

`--check-only` — лише перевірка правильності всіх форм; `--cpu N` —
прив'язати до ядра; `--samples`/`--warmup` — кількість раундів.

## Методика

- **Спершу правильність:** кожна програма в кожному раунді звіряється з
  незалежним Python-оракулом; неправильна відповідь зупиняє прогін.
- 1 warm-up + 7 раундів; порядок форм обертається в кожному раунді.
- Час старту (`(print 0)`) міряється в кожному раунді й віднімається.
- Три оцінки: медіана wall, медіана CPU (user+sys), мінімум wall.
- Фіксуються SHA, sha256 бінарника, rustc, Guix-профіль, CPU, load average.
- Навантаження використовують лише `eq/atom/cons/car/cdr/+/-`: на
  `33bfb53a` `(< 2 1)` повертає `"0"`, який `cond` трактує як істину, а
  `<`/`=` не мають bare-SENS механізму (див. #1413).

**Що стійке** (усі три оцінки в усіх п'яти навантаженнях): `sens`

**Що не стійке:** окремі значення. Розкид одного заміру доходить до
3–4 разів через навантаження машини; парні співвідношення `en`/`uk`
проти `sens` в окремих раундах опускались нижче 1.0. Це один локальний
прогін на спільній машині — найнижча сходинка доказу, не CI і не
незалежне відтворення.
