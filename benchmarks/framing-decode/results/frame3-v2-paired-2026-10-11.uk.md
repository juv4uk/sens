**Середовище:** GitHub-hosted AMD EPYC 7763, Linux 6.17.0-1022-azure, rustc 1.99.0, release build. 14 різних корпусів; **21 серія × 12 повторень для кожної з 6 lane**, у детерміновано перемішаному порядку у межах кожної серії. Усього **1764** сирих часових агрегати `ns/call` (по 126 на корпус), що доступні в артефакті. Обрахунок **p50 (медіана)** й **p95 (nearest-rank)** незалежно звірено з усіма сирими числами. Всі S3/T5 корпуси: `decode(encode(words)) == exact typed words` перевірено **до** вимірювань; для v2 також `encode(decode(v2)) == v2`.

**Вердикт:**

- T5 фізично коротший у **8 із 14** корпусів, Frame3 v2 коротший у **6 із 14**, рівності — 0; v2 коротший за v1 у **6** корпусах. Це **результат для фіксованих корпусів, не репрезентативний відсоток випадкових SENS-програм**.
- Порожня структура: **рангове тіло 0 Б** проти **11 Б повного S3/v2 файла** і **1 Б T5**. Виграш ранкера знищує фізична оболонка.
- 512 однакових W9: **1025 Б T5 проти 41 Б S3/v1 і v2** (приблизно 25× менший файл через REPEAT, а не GRAMMAR). 512 псевдовипадкових W9: **1025 Б проти 853 Б** (економія ≈16,8%). Це інший розподіл даних, тому не екстраполювати на загальну мову.
- Продуктивність: на короткому вкладеному QUOTE T5 encode `113` нс, S3/v2 encode `14920` нс; v2 має значні обчислювальні витрати. На 512 змішаних W9 S3/v2 encode `773764` нс проти T5 `14685` нс.
- Це **теплий in-process CPU** кодек-бенчмарк, не запуск CLI, не виконання програми, не cold start, не GPU/FPGA. Host CPU навантаження та кеші можуть змінювати абсолютні часи. Парне перемішування порядку знижує систематичний порядок lanes, але не дає автоматично довірчих інтервалів.
- **Формати мають різні вимоги:** T5 не містить CRC32 та S3 magic/version; v1/v2 включають CRC32. Тому є чесне порівняння фактичних фізичних байтів, але **не еквівалентна стійкість до пошкоджень**.
- **Без перемикання `.sens`**: математичний ранкер уже працює, але фізична оболонка не оптимальна. Відкриті роботи — мінімальний самоделімітований контракт, EOF, службові байти, семантичний code/data профіль, незалежна міграція та розумне обмеження CPU.

Запуск: `cargo run --locked --release -p sens --example frame3_v2_paired_bench --quiet`, із `FRAME3_BENCH_RAW=/tmp/sens-frame3-raw.tsv` для збереження кожного семпла.
