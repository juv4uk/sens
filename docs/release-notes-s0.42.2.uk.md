# SENS 0.42.2 — чернетка нотаток релізу

> **Чернетка підготовки, не опублікований випуск.** Пакет `s0.42.1` опубліковано; `s0.42.2` ще потребує релізних перевірок та окремого GO власника.

## Зміни, підготовлені в main

- REPL відображає імена Text7 у вибраній людській поверхні замість внутрішнього `#t7` токена.
- У REPL доступні D8-відображення видимих зв'язувань і D10-знімок середовища; інтерактивні перевірки виконуються через Zig/T5M → SENS.
- Допомога REPL відрізняє мовні форми від технічної команди оболонки `:env`.
- Додано механічну перевірку узгодження версій семи Cargo-crate, `Cargo.lock`, Guix та installer.

Контракт лишається 12.0. Ці нотатки не заявляють повноти виконання D1–D11 або числової драбини D12+.

## Очікувані файли випуску

Linux x86-64 CLI, Windows x86-64 CLI та MSI, macOS x86-64 й ARM64 CLI, `sens-cli-web.html`, `my-lisp-cli-web.html` і `install.sh`. Жоден із цих артефактів для `0.42.2` ще не зібраний у релізному workflow.
