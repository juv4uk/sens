# Архів дослідження RETURN/PROG: Rust-гіпотези не є законами SENS

**Статус:** ІСТОРИЧНЕ ДОСЛІДЖЕННЯ, не чинний семантичний оракул. Перенесено з активного Rust-test target 2026-10-09 за доктриною Contract 11.8 (ратифіковано D1–D9; D10 залишається дослідницьким).

## Що саме досліджували

У файлі було **сім Rust-тестів** про можливе походження `RETURN`, `PROG`, `GO` і CPS-трансформацій:

1. Порівняння двох осей `RETURN`: ціль нелокального виходу та вимога активного `PROG`.
2. Порівняння умовних батьків `APPLY`, `EVAL`, `LAMBDA`, `COND` з `DynamicExit`.
3. Гіпотеза, що CPS може відтворити результат, але змінює протокол виклику.
4. Гіпотеза про відмінні структурні механізми `GO` та `RETURN`.
5. Модель `PROG` як композиції локального `GO` та нелокального `RETURN`.
6. Розмежування нелокального виходу і мутації спільної комірки.
7. Відмова виводити exact-width координату, окремий корінь або D4-резидента лише з невдалого пошуку батька.

Це були **ручні Rust-переліки, структури та булеві константи**, а не виконання канонічної Lisp-програми з незалежним oracle. Зокрема `CPS_CAN_REPRODUCE_RETURN=true`, `CPS_PROVES_SAME_BASE_D4_PARENT=false`, `GO_LOCAL_STATE_MACHINE_DERIVED=true` тощо були вихідними припущеннями; `assert!(CONST)` не перетворює їх на доведений закон.

## Чому вилучено з активних Rust-тестів

Старі семантичні твердження не перевіряють ширини, точний домен, механіку D2 або фізичний T5. Вони не повинні визначати runtime, присвоювати функціям ратифікацію чи блокувати механічний GitHub-hosted Clippy. Показовий реальний блокер: `SENS exact compiler and T5 strict Clippy`, run `37982037237`, job `113994691563`, `clippy::assertions_on_constants` у зазначеному файлі.

**Не виправляти** це заміною `assert!(CONST)` на `const { assert!(CONST) }` заради зеленого CI — тоді довільні семантичні припущення залишилися б активними.

## Як повернути закон до чинної мови

Потрібні: посилання на ратифікований домен і координату; формулювання закону канонічною `ук`/Lisp-проєкцією; незалежний від Rust семантичний oracle (або формальний свідок), який перевіряє відмінність механізмів; відкритий огляд власника та оновлена provenance-історія. До цього `RETURN/PROG` залишаються дослідницькими питаннями, без автоматичного розширення D1–D9 чи D10.

Вилучено тільки активний файл **семантичних Rust-тестів**. Жодний файл фізичного SENS, сам runtime, компілятор чи драйвер не переписано.
