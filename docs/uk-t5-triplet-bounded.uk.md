# Канонічна українська проєкція ↔ фізичний T5 ↔ бітовий перегляд

**Межа цього кроку:** перевіряємо тільки D1 `ні/так`, D3 з наявної ратифікованої таблиці (`QUOTE/ATOM/CDR/CAR/EQ/COND/CONS`) з обмеженням цитованих даних, D3 EMPTY `()` та **D4 `п-п` (CAAR) лише над вкладеною парою CONS із QUOTE(())**, і структурні D2 слова, а не довільний D1–D9 код. `ук` ідентичності читаються з чинних `lib/domains/d1.lisp`, `lib/domains/d3.lisp` і `lib/domains/d4.lisp`, кодування джерела робить існуючий `scripts/migrate-three-pass.py`, фізичні байти — `scripts/sens_t5_codec.py`. Нових таблиць семантики немає.

Три *однойменні*, але **різні** файли вже є в `tests/fixtures/migration-d1-cond-cohort/`: `branch.lisp` — `(за-умовою (ні (перше ())) (так так))` з фінальним LF, `branch.sens` — 12 фізичних T5-байтів, а `branch` — згенерований перегляд `0/1` із рівно одним ASCII-пробілом між точними словами та рівно одним LF наприкінці.

Запуск перевірки:

```bash
python3 scripts/verify_uk_t5_triplet.py \
  --lisp tests/fixtures/migration-d1-cond-cohort/branch.lisp \
  --sens tests/fixtures/migration-d1-cond-cohort/branch.sens \
  --view tests/fixtures/migration-d1-cond-cohort/branch
```

Скрипт **тільки читає** оригінальну трійку й перевіряє без зміни жодного файла: T5 decode/encode побайтову тотожність, точні ширини слів, канонічний ASCII view, зворотне `ук` представлення з тих самих слів і повторне `ук`→справжній T5 через чинний трипрохідний механізм. У JSON містяться окремі SHA-256 трьох файлів і digest точних слів. Позитивна перевірка **не** є новою семантичною владою. Окремі Rust-тести реально виконують T5 на трьох поточних перевірених прикладах: D1 COND → `D1:1` (12 байтів), D3 CONS → `Pair(Nil,Nil)` (10 байтів), D4 CAAR → `Nil` (20 байтів). Джерело D4 `tests/fixtures/migration-d4-selector-cohort/caar.lisp` та його same-stem `.sens`/view перевіряються без перезапису.

Невідомі функції, англійські alias, довільні синоніми, Text7/D7, Numbers D24+, локальні зв’язування, **інші D4**, Text7/Number дані всередині цитування, CAAR без доведеної вкладеної пари, malformed D2, неправильний формат `ук`, некоректний T5, підмінений або відсутній view — **BLOCK**. Неможливо замінити `0` на `00` чи `000` із тим самим значенням. Виконання кількох top-level форм та загальний канонічний український renderer D1–D9 **ще не доведені**: ці задачі залишаються у #4430.

Джерело `.lisp` не перезаписувати, `.sens` не генерувати з неперевірених програм. Файл без розширення лишається похідним read-only *людським переглядом*, не машинним форматом і не кандидатом до `master`. Генерація інших файлів належить окремому агенту #4694. Цей proof не збільшує лічильник мігрованих історичних програм.

**Захист D4 від хибнопозитивних результатів:** `CAAR(QUOTE(EMPTY))`, `CAAR(CONS(QUOTE(EMPTY), QUOTE(EMPTY)))` (без внутрішнього CONS у CAR), неправильна арність, D4 CADR/DEFINE та взаємно підмінені T5+view за незмінного українського `.lisp` повинні давати BLOCK. Ратіфіковану загальну D3-підмножину, уже доставлену іншим агентом до `main`, цей PR не звужує й не замінює. Повний D1–D9 renderer, загальний semantic oracle та історична міграція залишаються відкритими.
