# Канонічна українська проєкція ↔ фізичний T5 ↔ бітовий перегляд

**Межа цього кроку:** перевіряємо D1 `ні/так`, D3 `перше/за-умовою`, `як-є` **лише над D3 EMPTY `()`**, D3 `сполучити` **лише над уже доведеними порожніми/вкладеними парами**, D4 `п-п` **лише над такою парою** і структуру D2. Не довільний D1–D9 код. `ук` ідентичності читаються з чинних `lib/domains/d1.lisp`, `lib/domains/d3.lisp` та `lib/domains/d4.lisp`, кодування джерела робить існуючий `scripts/migrate-three-pass.py`, фізичні байти — `scripts/sens_t5_codec.py`. Нових таблиць семантики немає.

Три *однойменні*, але **різні** файли є, зокрема, в `tests/fixtures/migration-d1-cond-cohort/`: `branch.lisp` — `(за-умовою (ні (перше ())) (так так))` з фінальним LF, `branch.sens` — 12 фізичних T5-байтів, а `branch` — згенерований перегляд `0/1` із рівно одним ASCII-пробілом між точними словами та рівно одним LF наприкінці.

Запуск перевірки:

```bash
python3 scripts/verify_uk_t5_triplet.py \
  --lisp tests/fixtures/migration-d1-cond-cohort/branch.lisp \
  --sens tests/fixtures/migration-d1-cond-cohort/branch.sens \
  --view tests/fixtures/migration-d1-cond-cohort/branch
```

Скрипт **тільки читає** оригінальну трійку й перевіряє без зміни жодного файла: T5 decode/encode побайтову тотожність, точні ширини слів, канонічний ASCII view, зворотне `ук` представлення з тих самих слів і повторне `ук`→справжній T5 через чинний трипрохідний механізм. У JSON містяться окремі SHA-256 трьох файлів і digest точних слів. Позитивна перевірка **не** є новою семантичною владою. Окремі Rust-тести реально виконують фізичний T5: D1 COND → `D1:1`, D3 CONS → `Pair(Nil,Nil)`, D4 CAAR → `Nil`. Крім `branch`, цей самий checker незалежно перевіряє **наявні** `tests/fixtures/migration-pair-cohort-main/pair-cons.{lisp,sens}` + `pair-cons` (10 байтів) та `tests/fixtures/migration-d4-selector-cohort/caar.{lisp,sens}` + `caar` (20 байтів). Власні Git SHA оригінальних фізичних файлів не змінюються.

Невідомі функції, англійські alias, довільні синоніми, Text7/D7, Numbers D24+, локальні зв’язування, інші D4-функції, довільні цитовані дані, malformed D2, неправильний формат `ук`, некоректний T5, підмінений або відсутній view — **BLOCK**. Неможливо замінити `0` на `00` чи `000` із тим самим значенням. Виконання кількох top-level форм та загальний канонічний український renderer D1–D9 **ще не доведені**: ці задачі залишаються у #4430.

Джерело `.lisp` не перезаписувати, `.sens` не генерувати з неперевірених програм. Файл без розширення лишається похідним read-only *людським переглядом*, не машинним форматом і не кандидатом до `master`. Генерація інших файлів належить окремому агенту #4694. Цей proof не збільшує лічильник мігрованих історичних програм.

**Нові негативні приклади:** `QUOTE(1)` і `QUOTE(CAR(EMPTY))` залишаються BLOCK — у тестовій підмножині QUOTE дозволений лише для `()`. `CONS(1,0)`, `CAAR(QUOTE(EMPTY))`, D4 CADR, хибна арність, некоректні закривальні D2 та одночасна підміна `.sens` і view при незміненому `.lisp` — теж BLOCK. Позитивні фікстури — тільки обмежений пройдений корпус, не загальне означення типів, виконання довільних програм чи релізний допуск.
