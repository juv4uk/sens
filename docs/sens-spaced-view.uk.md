# Людинозрозумілий двійковий перегляд SENS · #4694

Для кожної **допущеної виконуваної** програми одного stem зберігайте
`ім'я.lisp` (канонічна українська `ук` поверхня),
`ім'я.sens` (справжній фізичний бінарний T5) та
`ім'я` без розширення (**лише текстовий 0/1 перегляд**).
Останній файл не виконується як SENS і не стає новою семантичною владою.

## Команди

Перевірити наявну трійку **без запису**:

```sh
python3 scripts/sens_spaced_view.py \
  --root . \
  --sens tests/fixtures/migration-d1-cond-cohort/branch.sens \
  --verify
```

Згенерувати перегляд до **окремої** раніше створеної теки,
не переписуючи наявних джерел:

```sh
mkdir -p /tmp/sens-spaced-view-stage
python3 scripts/sens_spaced_view.py \
  --root . \
  --sens tests/fixtures/migration-d1-cond-cohort/branch.sens \
  --stage /tmp/sens-spaced-view-stage
```

Переглянути згенерований
`/tmp/sens-spaced-view-stage/tests/fixtures/migration-d1-cond-cohort/branch`
перед ручним оформленням окремого PR у власному заявленому cohort.
Повторний запуск у ту ж теку блокується: діє **no-clobber**.

## Канонічне відображення

Одна послідовність точних слів `[01]{1,9}`; між кожними двома словами —
**рівно один ASCII-пробіл**, наприкінці **рівно один LF**; без BOM,
порожніх рядків, коментарів, `0b`, `D3:`, лапок або цифри `2`.

```text
10 110 00 10 0 00 10 100 00 000 01 01 00 10 1 00 1 01 01
```

Різні довжини `0`, `00`, `000` принципово не тотожні. D2 й ратифіковані
точні домени визначають семантику. Трит `2` — **внутрішній транспортний
розділювач** T5, не слово мови і не текст перегляду.

Інструмент використовує тільки чинний `scripts/sens_t5_codec.py` та
строго перевіряє:

```text
encode_T5(decode_T5(.sens)) == .sens               # точні байти
render_view(decode_T5(.sens)) == bytes(ім'я)       # точний ASCII
encode_T5(parse_view(bytes(ім'я))) == .sens        # точні байти
```

Кожна операція дає машинозчитуваний JSON-результат із SHA-256 для
`.lisp`, `.sens`, людського перегляду та digest ширинних слів.
`semantic_oracle=NOT_VERIFIED_BY_VIEW_TOOL` і `release_admitted=false`
залишаються завжди: **наявність трьох файлів ще не доводить**, що довільна
українська проєкція відновлюється без втрат або програма виконується правильно.
Повна `ук ↔ exact domain ↔ T5` оберненість і executable oracle — задача
[#4430](https://github.com/juv4uk/sens/issues/4430).

Невідомий `.lisp`, застарілий перегляд, некоректні байти, symlink,
неправильний padding, небезпечний шлях чи повторний запис → `BLOCKED`.
`master` за [#3915](https://github.com/juv4uk/sens/issues/3915) —
лише для окремо сертифікованого фізичного `.sens`; текстовий перегляд
належить робочим/доказовим артефактам і не замінює двійковий файл.
