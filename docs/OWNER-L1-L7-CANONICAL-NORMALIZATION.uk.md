# Ратифікований власником перехід L1–L7: спадщина → канон

Дата: 2026-10-09. Єдине семантичне джерело рішень — власникова таблиця
в issue #5144: https://github.com/juv4uk/sens/issues/5144.

Реалізація лише механічна: чинний reader → L1–L7 → чинний exact-domain emitter
→ чинний T5-кодек → порівняння типізованого дайджесту з незалежним
оракулом. Заборонено створювати другий парсер, приписувати випадкові
координати функціям і змінювати канонічні очікування заради зеленого CI.

| Код | Критерій власника | Якщо доказу немає |
|---|---|---|
| L1 | COND: лише exact PredicateBit 1/0, вичерпання — структурне () | BLOCK без приведення truthiness |
| L2 | Виконувана клауза (t вираз) → (1 вираз); t не спеціальний | Не чіпати quoted/data |
| L3 | Executable-head → ратифікована координата D1–D10 за таблицею | BLOCK та D10-пропозиція |
| L4 | equal?/null → наявний D8-резидент; інакше машинно доведене розгортання законами D3 | BLOCK, не писати D3-розгортання вручну |
| L5 | structural-kind, identity-relation — retired | Прибрати з активного корпусу лише після запису археології |
| L6 | Застаріла форма фікстури | Перегенерувати канонічним тулом, не редагувати очікувані хеші вручну |
| L7 | Не парситься чинним reader | НЕ чіпати, окремий перелік на розсуд власника |

## Наявні механізми

- scripts/cond-modernize.py — чинний AST-розбір Lisp з межами токенів.
- scripts/migrate-three-pass.py — чинний виконавчий мапер і exact-domain emitter.
- lib/domains/d8.lisp — ратифікована D8-таблиця; не копіювати коди руками.
- scripts/sens_t5_codec.py — точний T5 транспорт і typed-SHA256; НЕ оракул семантики.
- scripts/migrate.py admit — єдиний остаточний шлях фізичного допуску.
- scripts/normalize-legacy-l1-l7.py — новий консервативний попередній адаптер.
- scripts/test_normalize_legacy_l1_l7.py — захист від здогадок.

Перший адаптер допускає лише локально доведені заміни L2 та наявний
D8-резидент L4. Стару truthiness, зниклу семантику, фікстури і файли з
невідомим синтаксисом залишає BLOCK. Це навмисно НЕ повний масовий
перетворювач. Непідтверджений файл має бути незмінним цілком.

## Факт перевірки

Без параметрів адаптер тільки читає один Git-pinned .lisp, показує JSON
і не публікує нічого. За незалежно одержаних oracle typed-SHA256 та
зовнішнього witness reference може підготувати лише зовнішню проєкцію
.words без перезапису. Збіг дайджестів підтверджує тотожність слова
переданому оракулом, але НЕ доводить правильність семантики оракула.

Остаточне схвалення вимагає незалежного виконуваного свідка, реального
Rust D2 reader, перевірки D1/D8/COND, відсутності неповних proof/HOLD і
зеленого GitHub-hosted CI. Фізичний кодек наразі приймає тільки D1–D9
ширини 1–9; D10 10-бітне слово не можна мовчки втиснути у чинний формат.

Поки є хоча б один BLOCK або червоний обов'язковий CI, не публікувати
.sens і не зливати механічний PR у main. Ізольований branch-sweep має
власний незалежний тріаж #5133.
