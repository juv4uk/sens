# Zig — чистий фізичний референс SENS · уточнення 14.10.2026

## Пріоритет чинної мовно-нейтральної доктрини

**Будь-яка мова програмування може застосовуватися до будь-якої задачі.** Це найновіше рішення власника записане в `AGENTS.md` і має пріоритет над колишніми формулюваннями «Zig лише для транспорту», «Python лише для CI» або «Rust лише для виконання». Zig, Rust, Python, Lisp, C/C++, Futhark та інші мови можна використовувати для інтерпретатора, компілятора, семантичних перевірок, GPU/FPGA, міграції, фізичних форматів і будь-якої іншої роботи.

**Чистота референсу — вимога до конкретного модуля, не обмеження мови.** Каталог `research/zig-codecs/` продовжує бути навмисно чистим фізичним референсом T5/F3C/E1. У цьому модулі не вводимо старі ідентичності `Sens8`, `SID8`, `Function8`, `W8`, старі реєстри диспетчеризації, не ототожнюємо їх з D8 через однакові фізичні біти.

Застосування Zig для інших задач, включно з міграційними інструментами, **дозволене**. Порівняльні посилання на інші реалізації, тексти `.lisp`, джерела Rust, зовнішні імпорти або слово «історичний» не означають автоматичного забруднення. Важливе правило — не підмінювати чинні ратифіковані доменні закони невірною спадковою семантикою.

## Автоматичний аудит

`scripts/ci_zig_purity.py` перевіряє **всі відстежувані Zig-файли всередині фізичного референсу** `research/zig-codecs/`, включно з новими файлами цього каталогу, без списку винятків для старих функціональних ідентичностей. Zig-код поза цим референсним модулем не блокується за місцем розташування або вибором ролі. Вивід `ZIG_PURITY_PASS files=N contamination=0` та структурований `sens-zig-purity.json` показують тільки чистоту перевіреної ділянки; не видавати їх за універсальний доказ відсутності всіх помилок SENS.

```bash
python3 scripts/ci_zig_purity.py --self-test
python3 scripts/ci_zig_purity.py --report /tmp/sens-zig-purity.json
```

## Ефективність

Підтверджувати заяви про швидкість, пам'ять, розмір або енергію **бажано** відтворюваними порівняльними бенчмарками з однаковими входами, перевіреним результатом, SHA, інструментарієм, повтореннями та первинними вимірами. Наявні окремо затверджені **обов'язкові парні T5/F3C бенчмарки** залишаються обов'язковими. Інші правильні зміни не блокувати лише через відсутність необов'язкового вимірювання.

Мова реалізації — вільний вибір. Нормативний закон SENS та достовірність тесту не залежать від мови.
