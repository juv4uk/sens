- [65400e64](https://github.com/juv4uk/sens/commit/65400e6446b518fec91f299dda7eae63c7119081), **15:42:40 UTC**, змінено тільки `lib/core.lisp`. Точна причина цієї **подальшої** відмови не доведена зміною операндів; не повертати голі `0/1`, щоб лише зробити CI зеленим.
- Пізніший центральний запуск [38592181657](https://github.com/juv4uk/sens/actions/runs/38592181657) на `baafcb64` — **SUCCESS**, але це не доказ, що кожен змістовний сценарій CLIPS або ручний кодек виконано окремо.

**Висновок для інших бібліотек:** знайдений голий арифметичний лічильник підлягає локальній явній кваліфікації D24 з SENS-вироком на нуль, одиницю, наступник і неправильний операнд. Не мігрувати всі `0/1` механічно: D1-предикати та біти структури мають інші закони.

### B. `lib/codec-d2.lisp`: структурний SENS-кодек, не байтовий T5

- [e1b24629](https://github.com/juv4uk/sens/commit/e1b246297d1b76337c9104ab255cdb9da64621a5), **15:42:30 UTC**, вперше додав `lib/codec-d2.lisp`, `crates/sens/tests/codec_in_sens.rs`, ручний `.github/workflows/sens-codec-in-sens.yml` і генератор D24+ констант. Кодек оголошує `codec-encode`, `codec-decode`, `codec-roundtrip`, застосовуючи D3 `ATOM/EQ/CAR/CDR/COND/CONS` та D4 `LAMBDA/DEFINE`.
- [baafcb64](https://github.com/juv4uk/sens/commit/baafcb64cb70d1a622d287317098e50a031fa3c9), **15:45:45 UTC**, змінив **лише** `lib/codec-d2.lisp`: внутрішню лямбду `r2` раніше викликали з **нульовою** кількістю аргументів; тепер її застосовано до `(011 r1)`, тобто хвоста `r1`. Commit message фіксує причину: `lambda: expected 1; received 0`. Синтаксична збалансованість дужок сама по собі **не доводить** round-trip.
- Тест [`codec_in_sens.rs`](../crates/sens/tests/codec_in_sens.rs) має дві поведінкові перевірки, які виконують вирази через SENS `Session`: `codec_written_in_sens_round_trips_every_shape` (атом, proper list, dotted, вкладений, improper tail) і `codec_really_transforms_and_is_not_identity`. Ручна команда репродукції: `cargo test --locked -p sens --test codec_in_sens -- --nocapture`.
- Імена `codec-open`/`codec-close` у джерелі — маркери **структурного** потоку; цей кодек **не** доводить канонічне фізичне D2/T5/F3C байтове кодування. Для байтового входу/виходу чинний механічний Zig транспорт і незалежна SENS-native перевірка лишаються розділеними.

**Стан доказу на цій перевірці:** джерело та історичні коміти прочитані; окремий ручний `codec_in_sens` тест **не запускався цією сесією**. Не називати його PASS на підставі Git commit message, Python-дзеркала чи загального CI.
