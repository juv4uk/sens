# Українська і санскритська поверхні D5

Цей зріз продовжує D1–D4 surface з #3283 і додає **D5 v2**, ратифікований
#3305 / #3331 / Contract 11.4.

```text
людське слово
    ↓
точний D5 + точні 5 bits
    ↓
чинний resident/law
```

Імена — лише проєкція. Вони не створюють resident і не можуть змінити
координату.

## Породжені селектори

Вісім селекторних назв не вигадані окремо: вони механічно продовжують D3/D4
surface law:

```text
A -> перше / ādi
D -> решта / śeṣa
```

Тому, наприклад:

```text
CADDR
-> перше-від-решти-від-решти
-> ādi-śeṣa-śeṣa
```

## Один вираз трьома поверхнями

English:

```lisp
(plus 2 (times 3 4))
```

Українська:

```lisp
(додати 2 (помножити 3 4))
```

Sanskrit IAST:

```lisp
(yoga 2 (guṇana 3 4))
```

У всіх трьох джерелах heads означають ті самі identity:

```text
D5:01010 PLUS
D5:10110 TIMES
```

## Статус лексики

Перевірені старі слова використано лише як лексичні донори. Їхні старі адреси
не переносяться. Нові санскритські D5 назви позначені `candidate`; їх можна
поліпшити окремим lexical review без зміни жодного біта.
