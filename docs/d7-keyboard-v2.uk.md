# D7 v2 — клавіатурний міграційний профіль SENS

**Ратифіковано власником: 2026-10-13.**

D7 v2 — не фонетичний закон і не новий Lisp. Це семибітне оборотне представлення текстових даних, необхідне для переходу старих .lisp файлів на машинні коди SENS.

- 128 точних координат `0000000..1111111`, без восьмого біта та без заповнення між комірками.
- `en`: ASCII identity.
- `uk`: позиційна відповідність клавіш української Enhanced клавіатури; 31 мала/велика пара та додаткові `ґ/Ґ` на `\\/|`, `є/Є` на `\`/~`; ASCII апостроф `'` незмінний.
- `san` у **людській таблиці D7**: **IAST** (`k`, `kh`, `ā`, `ṇ`, `ś`), не деванаґарі. Кожне з 128 точних семибітних слів має свою мітку. Залежні матри й знаки мають редакційний кружечок `◌` (`ā` ≠ `◌ā`); `◌∅` — вірама, `·` — данда; деякі розширені латинські знаки поза стандартною IAST позначені явно. Це **відображення, не новий машинний алфавіт**. У `knowledge/d7-keyboard-v2-ratified.json` поле `iast` є активною людською міткою; поле `san` з деванаґарі залишається **лише** для сумісності вже ратифікованого оборотного InScript-кодека v2, що ще приймає окремі Unicode-скаляри. Не трактувати багатолітерні IAST-мітки як однозначний безроздільний Unicode-кодек без окремого закону про межі клітинок.
- Три проєкції тієї самої машинної координати **не повинні означати один звук**.
- Обраний режим належить **цілому текстовому значенню**, не окремій комірці. Змішані мови потребують явно відмежованих значень/фрагментів.
- Дужки, апострофи та крапки у тексті є даними; граматика SENS/D2 живе поза D7. У `san` координата ASCII `'` може показувати інший знак, однак у `en` та `uk` це буквальний апостроф.
- Нормативна **повна таблиця 128 рядків**: `knowledge/d7-keyboard-v2-ratified.json`.
- Нормативний договір: `contracts/d7-ratification.lisp`. Rust-проєктор: `crates/sens/src/d7_keyboard.rs`.
- `knowledge/d7-ratified.json` — **архівний опис звукової v1 (126/128)**; чинна `lib/domains/d7.lisp` уже містить **D7 v2 (128/128)** разом із `knowledge/d7-keyboard-v2-ratified.json`. Історична таблиця не є джерелом для нових файлів.
- **Уточнення власника:** за D7 v1 ще нічого не було мігровано. Отже, **перетворювати v1→v2 нічого і не потрібно**; не запускати історичну конверсію, не ставити її передумовою міграції та не створювати з неї CI-блокер. Нові текстові дані відразу кодуються за ратифікованою D7 v2; функціональні коди зберігають власні домени.
- Невідомі символи (наприклад, додаткові ведичні знаки, інші Unicode-писемності) відхиляються. Не дозволено мовчазну втрату символів.
- Екранне формування складів, IAST-латинізація, шрифт і Unicode-нормалізація **не визначають бітову тотожність**. Відображення `kh` складається з двох символів, але відповідає **одній** W7-координаті; голий IAST-текст може бути неоднозначним для зворотного розбору. Старий Devanagari-кодек залишено сумісним, без мовчазного перекодування існуючих даних.
- Ратифікація таблиці — **не доказ завершеної міграції** всіх файлів, не дозвіл видаляти стару реалізацію та не автоматичне схвалення невідомих символів.

## Відтворювані перевірки

`cargo test -p sens d7_keyboard` для незмінного машинного профілю та `cargo test -p sens iast_` для нового читабельного відображення (якщо Rust доступний): кожна з 128 координат повинна проходити round-trip у всіх трьох проєкціях; усі 128 виходів кожної проєкції повинні бути унікальними; тестувати український апостроф, ґ/є, санскритські матри/віраму, щільне пакування W7 і некоректний padding.

Вхідні джерела для клавіатурних позицій: https://www.kbdlayout.info/KBDUR1/ ; https://www.kbdlayout.info/KBDINDEV/ ; Unicode деванагарі: https://www.unicode.org/versions/Unicode18.0.0/core-spec/chapter-12/

**Сфера застосування:** міграція даних; жодних нових callable-резидентів D7.

## Запис літер і символів у таблиці D7

Як і в інших доменах, **літери пишемо без лапок**, а **знаки, цифри та поєднувальні символи — у лапках**. Приклади: `(ук л)`, `(san k)`, `(san kh)`, `(san "◌ā")`, `(en k)`, `(ук "'")`, `(en "1")`, `(en "\\\"")`. Апостроф і будь-який інший друкований знак мають буквальний вигляд; непотрібні псевдоніми `U+XXXX` у таблиці скасовано.

Лапки — синтаксис текстової таблиці, а не частина 7-бітного кодового значення. Декодер `scripts/domain_tables.py` відокремлює записаний знак від ідентичності W7. Усі машинні координати визначені нормативним JSON. `LISP` у D7 залишається `()`, тому таблиця не створює викличних імен.
