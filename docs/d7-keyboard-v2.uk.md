# D7 v2 — клавіатурний міграційний профіль SENS

**Ратифіковано власником: 2026-10-13.**

D7 v2 — не фонетичний закон і не новий Lisp. Це семибітне оборотне представлення текстових даних, необхідне для переходу старих .lisp файлів на машинні коди SENS.

- 128 точних координат `0000000..1111111`, без восьмого біта та без заповнення між комірками.
- `en`: ASCII identity.
- `uk`: позиційна відповідність клавіш української Enhanced клавіатури; 31 мала/велика пара та додаткові `ґ/Ґ` на `\\/|`, `є/Є` на `\`/~`; ASCII апостроф `'` незмінний.
- `san`: позиційна проєкція деванагарі за InScript, **не SLP1**; для відсутніх/дубльованих клавіатурних скорочень — явно обрані ASCII-позиції. Одна комірка в цій редакції відображає один Unicode scalar; знаки деванагарі можуть компонуватися при виведенні.
- Три проєкції тієї самої машинної координати **не повинні означати один звук**.
- Обраний режим належить **цілому текстовому значенню**, не окремій комірці. Змішані мови потребують явно відмежованих значень/фрагментів.
- Дужки, апострофи та крапки у тексті є даними; граматика SENS/D2 живе поза D7. У `san` координата ASCII `'` може показувати інший знак, однак у `en` та `uk` це буквальний апостроф.
- Нормативна **повна таблиця 128 рядків**: `knowledge/d7-keyboard-v2-ratified.json`.
- Нормативний договір: `contracts/d7-ratification.lisp`. Rust-проєктор: `crates/sens/src/d7_keyboard.rs`.
- Старий `knowledge/d7-ratified.json` та `lib/domains/d7.lisp` зберігаються для **читання історичного v1**. Нові файли не повинні використовувати їхній старий мапінг.
- Старе `Text7` або функціональні коди не переводити в нову D7 простою заміною назви: для переводу потрібен явний декодер v1 і кодування v2.
- Невідомі символи (наприклад, додаткові ведичні знаки, інші Unicode-писемності) відхиляються. Не дозволено мовчазну втрату символів.
- Екранне формування складів, шрифт, Unicode-нормалізація **не визначають бітову тотожність**. Композиція деванагарі та змінений Unicode-вигляд можуть не мати однозначної зворотної відповідності без канонічного потоку кодових точок.
- Ратифікація таблиці — **не доказ завершеної міграції** всіх файлів, не дозвіл видаляти стару реалізацію та не автоматичне схвалення невідомих символів.

## Відтворювані перевірки

`cargo test -p sens d7_keyboard` (якщо Rust доступний): кожна з 128 координат повинна проходити round-trip у всіх трьох проєкціях; усі 128 виходів кожної проєкції повинні бути унікальними; тестувати український апостроф, ґ/є, санскритські матри/віраму, щільне пакування W7 і некоректний padding.

Вхідні джерела для клавіатурних позицій: https://www.kbdlayout.info/KBDUR1/ ; https://www.kbdlayout.info/KBDINDEV/ ; Unicode деванагарі: https://www.unicode.org/versions/Unicode18.0.0/core-spec/chapter-12/

**Сфера застосування:** міграція даних; жодних нових callable-резидентів D7.
