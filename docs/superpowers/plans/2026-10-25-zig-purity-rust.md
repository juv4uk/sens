# Перенесення механічної перевірки Zig на Rust

Мета: замінити Python-перевірку застарілих ідентичностей у всіх tracked
Zig-джерелах автономним Rust-інструментом. Семантика SENS не змінюється.

1. Перенести позитивні й негативні приклади ідентифікаторів та файлові
   перевірки (symlink, hardlink, відсутній файл) у Rust unit tests.
2. Реалізувати сканування tracked `*.zig`, точні діагностики й звіт.
   SHA-256 не переносити: він не визначає результат механічного контролю.
3. Замінити виклики у короткому CI і migration gate; видалити стару
   реалізацію Python, лишити один Rust guard та shell launcher.
4. Через pinned Guix запустити Rust unit tests, аудит реальних Zig-файлів
   і контроль навмисного забруднення. Перевірити diff, коміт і push main.

Критерій: чисте джерело проходить, забруднення/неприпустимі файли дають
ненульовий exit status; чинний D8 не забороняється. JSON schema v4 не
містить source_sha256. Мовні закони лишаються у SENS, фізичні — у Zig.
