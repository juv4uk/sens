# СУПЕРЕЧНІСТЬ У ПРАВИЛАХ: тест забороняє ідіом, який вживають 617 файлів

Автор: агент Vimṛśa, 2026-10-25. Знайдено під час роботи над червоними.

## Що саме

`tests/test_core_ukr_primary_projection.py:236-238` — **два твердження про ОДИН файл**:

```python
self.assertIn("((атом? (як-є ())) так)", racket_core)   # «так» мусить бути РЕЗУЛЬТАТОМ
self.assertNotIn("(так ", racket_core)                   # «так» не сміє бути УМОВОЮ
self.assertNotIn("(так\n", racket_core)
```

А файл містить, наприклад:

```lisp
(визначити довжина-до
  (функція (значення накопичувач)
    (за-умовою
      ((атом? значення)
       (за-умовою
         ((тотожне? значення (як-є ())) накопичувач)
         (так (перше (як-є ())))))
      (так (довжина-до (решта значення) (додати накопичувач число-один))))))
```

Тут `(так (перше (як-є ())))` — це **клауза «інакше»**: умова `так`, результат
`(перше …)`. Те саме `(так B)` у `зворот-до`, `відобразити-до`, `відсіяти-до`,
`згорнути`.

## Чому це суперечність, а не мій здогад

**Той самий ідіом уживають 617 `.lisp`-файлів, 3550 входжень** (з них 280 — у
`tests/semantic/`). Тобто `(за-умовою (умова A) (так B))` — **усталена форма мови**,
а не локальний відступ.

І **сам тест** вимагає, щоб `так` був результатом — `((атом? (як-є ())) так)` — тобто
тест **визнає** `так` значенням. Але наступним рядком **забороняє** ту саму форму,
коли `так` стоїть **умовою клаузи «інакше»**.

**Обидва твердження не можуть бути виконані одночасно для файла, який користується
канонічним ідіомом «інакше».**

## Чому я НЕ лагоджу це сам

Це **мовний закон**, а не механіка:

- **Варіант A:** виправити файл — переписати клаузи «інакше» без `(так …)`. Але тоді
  файл **відійде від ідіому**, який уживають 617 інших файлів.
- **Варіант B:** виправити тест — зняти `assertNotIn("(так ", …)`, лишивши
  `assertIn("((атом? (як-є ())) так)")`. Але це **ослаблення перевірки**.

**Обидва — рішення власника.** Умова користувача прямо каже: «важливі зміни
семантичних законів залишаються рішенням власника» і «не вимикати корисних тестів».

## Що я встановив додатково

- Файл `racket/examples/constitution.lisp` (той, що перевіряє `program`) має
  **нуль** `(так ` — отже падає **не він**, а асcерт про `racket_core`.
- `test_core3_ukr_projection` падає з `Core3 exact D3/D4 law or quoted data changed` —
  це **знімок**, інша причина, не ця суперечність.
