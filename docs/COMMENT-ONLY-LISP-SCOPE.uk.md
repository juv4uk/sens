# Коментарні оригінали Lisp — не вигадані програми SENS

Цей аудит не змінює семантику SENS. Деякі історичні файли .lisp можуть містити тільки коментарі й порожні рядки. Вони позначаються COMMENT_ONLY_REVIEW_PENDING — лише для перегляду власником.

Команда: `python3 scripts/audit_comment_only_originals.py --out /tmp/comment-only-originals.json`

Джерело даних — канонічний `scripts/report_original_migration_candidates.py`. Для кожного кандидата звіряються SHA Git-blob і реальні байти, шлях без симлінків, відсутність однойменного .sens. Не відбувається запису, змін оригіналів чи вибору historical/current era.

Допускаються лише порожні рядки та рядки, в яких перший непробільний символ — крапка з комою. Форми, символи, літерали, блокові коментарі й невідомий синтаксис не класифікуються як коментарні.

Перевірений зразок: `lib/core2.lisp`, Git blob `9a39a1d341dde7faf3a1899b52f78a7b1e931783`, — коментарний профільний маркер. Це не дозвіл створити порожній .sens: власник окремо вирішує, чи це дані профілю, чи файл завантаження з контрактом.

Лічильники оригіналів і міграції залишаються незмінними. Фізичних .sens не створюється; виконувані файли не зараховуються як переведені без справжнього D2 і незалежного оракула. D2 лишається власником структури; T5 є лише фізичним транспортом.

Мета — дати агентам окрему SHA-підтверджену чергу ручного розгляду, а не видавати відсутність форм за семантичну міграцію.
