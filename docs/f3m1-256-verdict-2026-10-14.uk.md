## Чесні межі

- Це F3M-1 (носій `.f3m`), **не** канонічний T5 `.sens`. Твердження README про «256/256» стосується F3M-1 — і воно **підтверджене на бінарнику**.
- «Виконано» тут = `decode_payload` → `parse_canonical_binary` → `eval_parsed_expressions` → `PhysicalT5Program::execute`, з паритетом value/output між двома шляхами.
- Перевірено один прогін на одній машині; для повної незалежності потрібен другий прогон/інша архітектура.
