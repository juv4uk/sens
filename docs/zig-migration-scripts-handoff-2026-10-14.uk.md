## 1. Проблема

Фізичний транспорт SENS переїхав на **Zig** (`research/zig-codecs/`: `t5/t5.zig`,
`f3c/f3c.zig`, `transport/e1.zig`, `domain_ladder.zig`, `domain_e3_numeric.zig`).
Ширина слова **є** ідентичністю (драбина доменів), а фізичні байти дає сам Zig-кодек.

Але **скрипти міграції** (`scripts/migrate.py`, `scripts/migrate-t5m-batch.py`,
`scripts/migrate-three-pass.py`, `scripts/sens_t5_t5m_codec.py` та похідні) лишились на
**старій реалізації кодека** (Rust-ера, Python). Через це:

- конвертер у SENS може давати **не ті байти**, що дає чинний Zig-кодек;
- «успіх» скрипта не є доказом, що фізичний носій канонічний для нового транспорту;
- частина перевірок міграції міряє стару реалізацію, а не чинний кодек.

## 2. Що зробити

1. **Єдиний оракул — Zig-кодек.** Скрипти міграції мають отримувати фізичні байти
   через сам Zig-кодек (`t5.encode` / `f3c.encode`), а не через власну Python/Rust
   реалізацію. Python-кодек можна лишити як зручність, але **не** як джерело істини.
2. **Точні слова, а не імена.** Вхід для кодека — послідовність **явно типізованих**
   доменних слів (D1..D10, ширина = ідентичність). Жодного історичного реєстру
   імен і жодного виведення домену з десяткового числа.
3. **Перевірка скриптів (обов'язкова).**
   - byte-exact: `encode(слова)` із Zig-кодека == фізичний носій, який пише скрипт;
   - round-trip: `decode(encode(слова)) == слова` без втрати ширини/провідних нулів;
   - негативні свідки: усічення, битий кадр, неканонічний T5/F3C — fail-closed;
   - паритет: для кожного скрипта — порівняння з чинною Rust-реалізацією там, де
     #5770/#5771 цього вимагають.
4. **Ніяких ретро-D8.** Згідно з чинним контрактом (AGENTS.md,
   `OWNER-ZIG-D8-HISTORICAL-FIREWALL-20261014`): у Zig і в скриптах — лише сучасна
   ратифікована драбина; історичний SID8/Sens8/Function8/W8 — архівна provenance,
   не еталон.

## 4. Межі

- Це **не** твердження, що всі скрипти вже переведено — навпаки, їх треба перевести.
- Тулкіт доводить механічний транспорт на одному прикладі; він **не** є
  семантичним оракулом SENS і не виконує програму.
- Семантику визначає лише SENS; зміна мовного транспорту (Rust→Zig) не створює
  нових доменних законів.
