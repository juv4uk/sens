# D10: точність годинників, SDR та астрономічний час

Поточний власниковий запит: черпати перевірювані закони із захоплень, координуючи авторські репозиторії і спільну D10 драбину.

## Кандидат: HADAMARD-VARIANCE — дисперсія Адамара

Сфера: метрологія частоти, кварцові генератори, астрономічний час, PLL/SDR, вимірювання частоти на ESP32/FPGA, акустичні генератори.
Донор: NIST SP 1065, Handbook of Frequency Stability Analysis, §§5.2.8–5.2.9.
https://www.nist.gov/publications/handbook-frequency-stability-analysis

Для N рівномірно виміряних дробових частот y та m>0, при N≥3m, утворюємо суміжні m-відлікові усереднення a_i і середнє квадрата других різниць a_i-2*a_(i+m)+a_(i+2m), поділене на 6.
Точна формула: HVAR(y,m) = SUM_i((a_i - 2*a_(i+m) + a_(i+2m))^2) / (6*(N-3*m+1)), i=0,...,N-3m.
Позитивні приклади: y=(0,0,1),m=1 => 1/6; y=(0,0,0,1,0),m=1 => 5/18; y=(0,0,1,1,0,0),m=2 => 2/3.
Контрприклад: y=(1,2,3,4,5,6),m=1 => 0, хоча двовибіркова дисперсія Аллана при лінійному частотному дрейфі ненульова.

Сусідні задачі: #4909 вже досліджує ALLAN-VARIANCE і не дублюється тут. HADAMARD-VARIANCE показує інший статистичний закон, але може бути похідним від арифметики й операцій над списками, а не новим примітивом D10. Тому статус — лише pending-review в канонічному TSV, selected=false і ratified=false.

Леджер: knowledge/d10-proposal-ledger.tsv, рядок D10P-0008. Джерело: knowledge/d10-hadamard-variance-proposal-20261009.json.
Реальний незалежний Scheme R6RS донор: tests/oracles/d10_hadamard_chez.ss, 15 спостережень.
Перевірка: scripts/check_d10_hadamard_proposal_v1.py, 9 негативних контролів, Git-ревізія донорського JSON має існувати.

## Як не перетворити гвардію на стіну

До SELECT запис у леджері мусить бути легальним: для незалежного дослідження він має явно позначатися NOT-A-MIGRATION-BLOCK, містити існуюче джерело з Git SHA і статус pending-review/ratified=0. Він не дає координату й не змінює інвентар сам по собі.
Справжній міграційний BLOCK не дозволено маскувати цим маркером. Коли стане доведеною незалежна мовна семантика, потрібне окреме owner review, нова append-only SHA-транзакція, позитивні та негативні тести та — незалежно — ратифікація. D2 лишається власником структури та керування.
