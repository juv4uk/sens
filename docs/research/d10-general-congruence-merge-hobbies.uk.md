# D10 — Узгодження циклів без прив'язки до обладнання (RESEARCH/HOLD)

**Пропозиція:** \`MERGE-CONGRUENCE-CONSTRAINTS\`  
**ук:** \`звірити-цикли\`; **укр:** \`узгодити-модульні-обмеження\`  
**Стан:** НЕ selected, НЕ ратифіковано, НЕ код D10; координати немає.

Наші обговорення годинників, радіозв'язку/SDR, FPGA, аналогових обчислень, музичних ритмів, астрономічних періодів, санскритської метрики та Prolog/Advice Taker мають один **математичний** спільний випадок: узгодження цілочисельних циклічних обмежень. Ніякого MCU, SI, протоколу, UTC чи регістрів сюди не вносимо.

Для списку \`(rᵢ,mᵢ)\`, де \`mᵢ > 0\`, шукаємо \`x ≡ rᵢ (mod mᵢ)\`. За сумісності повертаємо \`0 ≤ x < L\`, \`L = lcm(mᵢ)\`. За несумісності — **найпершу в оригінальному порядку пару (i,j)** та \`g = gcd(mᵢ,mⱼ)\`, для якої \`(rᵢ − rⱼ) mod g != 0\`. Порожня система має представник \`(0,1)\`. Нецілочисельні залишки, \`m ≤ 0\`, \`bool\` — окрема помилка області визначення, не математичний конфлікт.

## Позитивні та негативні свідки

- \`(2 mod 6),(5 mod 9) → 14 mod 18\`: модулі не взаємно прості, але сумісні.
- \`(2 mod 3),(3 mod 5),(2 mod 7) → 23 mod 105\`.
- \`(2 mod 3),(4 mod 6) → CONFLICT (0,1)\`: мінімальна перешкода \`gcd(3,6)=3\`, різниця не ділиться на 3.
- \`(0 mod 4),(0 mod 6),(1 mod 2)\`: перша суперечлива оригінальна пара \`(0,2)\`, а не лише невдача згорнутого алгоритму.

Перевірки: незалежний перебір повного періоду, extended Euclid, **справжній** \`sympy.ntheory.modular.solve_congruence\` в GitHub CI, малі вичерпні системи з двома й трьома обмеженнями, інваріанти перестановок, і негативні мутації.

Першоджерела (не авторство SENS): [SymPy solve_congruence](https://docs.sympy.org/latest/modules/ntheory.html), [SageMath CRT_list](https://doc.sagemath.org/html/en/reference/rings_standard/sage/arith/misc.html). Наше уточнення «перший конфлікт в оригінальному порядку» — власна формальна специфікація, не твердження, що саме такий API дає SymPy/Sage.
