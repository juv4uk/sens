# #2485 — Мінімальний двійковий виконавець із доменним скоупом

Статус: P0 дослідницька реалізація.
Батьківська онтологія: #2490.
Доменний фаєрвол: #2508 / #2509.
Донор точного Q: #2494 / PR #2500.
Конвергенція селекторів: #2495 / PR #2585.

## Результат

Мінімальний двійковий виконавець Core-Math (`benchmarks/core-math-binary-exec/`) оновлено з плаского арифметичного помічника `(bits, factor) -> bits` до повної канонічної онтології з #2490:

```text
семантичний об'єкт = двійкове число + оголошений домен + доведений закон
```

### 1. Оголошені домени

Виконавець явно типізує кожен семантичний об'єкт і закон:
- `Domain::SelectorPath`: змінні шляхи селекторів точної ширини з коренями Core D3 `101` (First) та `110` (Rest).
- `Domain::QGroupFactor`: групові координати факторів точного Q з коренями `0` (адитивна сім'я) та `1` (мультиплікативна сім'я).

### 2. Доменно-скоуповане виконання

Семантична операція:
```rust
apply(law: &Law, parent: &SemanticObject, delta: &BinaryNumber) -> Result<SemanticObject, Error>
```
забезпечує:
1. `parent.domain() == law.domain()`, завершуючись помилкою `Error::DomainMismatch` при будь-якому міждоменному застосуванні.
2. `delta.width() == 1`, гарантуючи одноелементне двійкове розширення координати.
3. `law.factor() == 10₂`, обчислюючи `child = 2 * parent + delta` з шириною `width = parent_width + 1`.

### 3. Інтегровані донорські закони

#### SelectorPath (#2485, #2495)
- Закон: `extend(selector, b)(x) = selector(project_b(x))`.
- 252 обмежених семантичних свідки до глибини суфікса 5.
- Необмежений бітовий носій: перевірено вхід шириною 4096 біт, що породив 4097-бітний вихід.
- Атака перестановок слотів виявляє довільні перестановки нащадків.

#### QGroupFactor (#2494, #2500)
- Корені: `0` (адитивна сім'я), `1` (мультиплікативна сім'я).
- Біт ролі: `0` (інверсія), `1` (частка).
- Нащадки: `00` (NEG), `01` (SUB), `10` (RECIP, частковість у 0), `11` (DIV, частковість при y=0).
- 104 визначених точних випадки Q + 8 невизначених випадків на 7-елементному корпусі.
- Анти-нумерологія: 22 із 24 довільних перестановок 4 слотів нащадків порушують закон факторизації, що доводить канонічну структуру факторів.

### 4. Доменний фаєрвол (#2508, #2509)

Той самий бітовий механізм `y = 2x + b` спільно використовується `SelectorPath` та `QGroupFactor`, проте:
- `apply(selector_law, q_object, delta)` -> `Err(DomainMismatch)`.
- `apply(q_law, selector_object, delta)` -> `Err(DomainMismatch)`.
- Семантичні об'єкти з однаковими бітовими рядками (`10` SelectorPath проти `10` QGroupFactor) не є рівними: `sel_10 != q_10`.
- Стирання домену веде до амбівалентності (`AMBIGUOUS-WITHOUT-DOMAIN`).

### 5. Архітектурні інваріанти

- Нуль зовнішніх залежностей crate (розділ `[dependencies]` заборонено в `Cargo.toml`).
- Для виконання не потрібні середовище Lisp, JSON, AST, SHA-геші, записи реєстру чи кеші.
- Породжені двійкові об'єкти негайно придатні для повторного застосування в наступних законах у межах того самого домену.
