# D10 v13 — 70 дослідницьких законів

Пропонуються 70 окремих семантичних кандидатів із історичних описів потоків, шляхів, хеш-таблиць, CLOS MOP та числових операцій. Це попередні визначення для перевірки; F2/F3 не підтверджені, координати не призначено, ратифікацію відкладено.

Попередній інвентар D10 v12 залишається 827/1024 до атомарного оновлення канонічного покажчика.
