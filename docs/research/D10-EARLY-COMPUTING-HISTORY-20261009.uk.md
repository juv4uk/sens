## Точна кандидатура цієї хвилі

Див. [`knowledge/d10-quine-prime-implicants-20261009.json`](../../knowledge/d10-quine-prime-implicants-20261009.json)
та [тести](../../tests/test_d10_quine_prime_implicants.py).

**Назви:** `ук=прості-імпліканти`, `укр=усі-максимальні-куби-булевої-функції` — *лише кандидат у людському досьє*, не визначена поверхня нового коду.

Для повної скінченної бітової області задано точні множини:
`ON` (функція має бути істинна), `OFF` (має бути хибна),
`DC` (на розсуд реалізації), усі попарно не перетинаються.

Повертаємо **всі** куби з алфавіту `0/1/-`, які:

- покривають хоча б один `ON`-випадок;
- не покривають жодного `OFF`-випадку;
- не можуть бути розширені до більш загального куба без покриття `OFF`.

Результат відсортований детерміновано. `-` означає вільний біт,
а не третє логічне значення SENS і не порушення предикатів D1.
Перелік **усіх** prime implicants не дорівнює одному мінімальному
булевому виразу, схемі FPGA або proof search результату.

### Приклади

```text
width=2, ON={1,3}, DC={}       → [-1]
width=2, ON={1,2}, DC={}       → [01, 10]
width=2, ON={0},   DC={1}      → [0-]
width=3, ON={1,3,5,7}, DC={}   → [--1]
width=0, ON={0}, DC={}         → [""]   (нуль змінних, істинна функція)
width=2, ON={}, DC={1,2}      → []     (нічого обов'язково істинного)
```

## Межа D10 проти бібліотеки

Булева алгебра та скінченний перебір можуть побудувати ці куби
як похідну бібліотечну функцію. Однак їхня *сукупна* семантика
відрізняється від окремих `AND/OR/NOT`, від перевірки `EQ`
і від мінімізації фізичної схеми.

Тому статус: **HOLD / CORE VS CORE-MATH/AI LIBRARY**. Ні декілька
застосувань, ні відсутність назви в таблиці не доводять необхідність
окремого resident D10. Жодних самовільних координат, ратифікації,
перенесення D2-керування або апаратної інструкції.

## Нові архівні черги агентів

1. **Quine/McCluskey** — перевірити термінологію prime/essential/minimum,
   правила don't-care й повноту двох незалежних алгоритмів;
   ніхто інший не змінює цю кандидатуру без claim у #4013.
2. **IPL/Logic Theorist** — знайти першоджерела правил різниця→підціль,
   порівняти з D9/D10 `PROVE-RULE`/планувальниками; запропонувати
   тільки самостійний закон зі свідком та falsifier.
3. **Plankalkül** — дослідити типізовані поля/масиви, не підмінюючи
   затверджені D2 форми чи фізичні width.
4. **Lovelace/Babbage** — дослідити представлення нот і символів як
   машинних чисел без втрати точної семантичної тотожності D7/доменів.
5. **Bush/Memex → proof provenance** — чи додає асоціативна стежка
   щось поза вже вибраними knowledge/proof rules?
6. **Historical checks** — кожен донор має бути прочитаний у контексті
   часу; архівний факт не перезаписувати як сучасну догму.
