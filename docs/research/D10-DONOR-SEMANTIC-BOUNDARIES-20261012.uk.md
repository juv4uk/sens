# D10: ім'я донора не замінює семантичний закон SENS

Перевірено 2026-10-12. Авторитет: `knowledge/d10-v18-semantic-inventory.json`, 1024 ратифіковані координати. Ця нотатка не змінює контрактів, кодів або ратифікації.

| Ідентичність | Контракт SENS і коротка назва | Що відрізняється від сучасного джерела |
|---|---|---|
| `FUNBOUNDP` | **Істина, коли визначення функції відсутнє.** `ук: функція-не-визначена?` | [CLHS FBOUNDP](https://www.cs.cmu.edu/Groups/AI/html/hyperspec/HyperSpec/Body/fun_fboundp.html) повертає істину **коли ім'я зв'язане**. Тут протилежна полярність; за збігом імені її не переносити. |
| `FIXNUM->FLONUM` | Перетворити точний fixnum на flonum; **уже floating** залишити незмінним. `ук: фікснум->флонум` | [R6RS](https://r6rs.org/final/html/r6rs-lib/r6rs-lib-Z-H-12.html) дозволяє числову втрату точності й не встановлює SENS-gate для вже floating. |
| `SUBTYPEP` | Перевірити включення множин специфікаторів типів. `ук: підтип?` | [CLHS SUBTYPEP](https://www.cs.cmu.edu/Groups/AI/html/hyperspec/HyperSpec/Body/fun_subtypep.html) визначає два результати, другий — достовірність. Не додавати їх у SENS без окремого контракту. |
| `REMPROP` | Видалити властивість та повідомити, чи вона існувала. `ук: вилучити-властивість!` | [CLHS REMPROP](https://www.cs.cmu.edu/Groups/AI/html/hyperspec/HyperSpec/Body/fun_remprop.html) повертає generalized boolean, але змінює список властивостей. |
| `LISTEN` | Запитати про негайну наявність символу **без споживання**. `ук: символ-доступний?` | [CLHS LISTEN](https://www.cs.cmu.edu/Groups/AI/html/hyperspec/HyperSpec/Body/fun_listen.html) є предикатом, хоча ім'я донора без `?`. |
| `BRIDGE` | Частково перетворити представлення, зберегти джерельне спостереження **без припущення семантичної еквівалентності**. | Не ототожнювати обидва подання автоматично. |

**Правило скорочення:** спочатку знайти координату, `stable_id` та `behavior` в інвентарі, потім формувати `ук` без зміни полярності, побічних ефектів, точності, кількості результатів чи частковості. `укр` пояснює саме цей закон. Зовнішній стандарт — джерело для перевірки, не безумовна заміна затвердженого контракту SENS.
