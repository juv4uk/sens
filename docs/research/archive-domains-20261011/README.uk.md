Це **нормативно неактивні** оригінальні файли з історичних GitHub PR. Перенесення у `main` зберігає початкові Git blob SHA без переписування, але **не** означає допуск коду до виконання, відбір D10 чи зміну ратифікованих D1–D9.

Кожен файл лежить у `prNNNN/<оригінальний-шлях>` і має той самий Git blob, що й історична гілка. Жоден із вкладених workflow-файлів не встановлюється у `.github/workflows/` репозиторію. Історичні скрипти й Rust-файли не входять у збірку.

Перевірки й перенесення в канонічні домени потребують окремого узгодження з поточним станом `main`, дедуплікації поведінкових законів, незалежних свідків і профільного CI. Права на D10-ратифікацію цей архів не надає.
