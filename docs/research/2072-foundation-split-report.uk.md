# #2072 — перші структурні нижні межі під успадкованим bīja3

Лише дослідження. Цей результат не ратифікує новий bīja3 і не змінює production semantics.

## Питання

Перш ніж доводити мінімальність восьми успадкованих насінин, треба перевірити, чи вони взагалі належать до одного типу фундаменту.

Перший зріз ізолює **алгебру значень/даних** і не використовує припущення про evaluator/control.

Абстрактні ролі:
```text
ground
make-pair
left
right
atom-class
atom-identity
choose
```

Історичні назви примітивів не є доказом.

## Метод

Для кожної цільової ролі її вилучаємо та перебираємо всі добре типізовані вирази до розміру 9, складені з решти ролей, на adversarial finite universe.

Вирази дедуплікуються екстенсійно, тому пошук рахує семантичні функції, а не різні записи.

Негативний bounded search не є універсальною теоремою. Для кожної ролі додано окремий інформаційний/invariance witness.

## Нижні межі

- Без `left` прихований лівий компонент пари не з’являється з правої проєкції.
- Для `right` маємо симетричний аргумент.
- Без `make-pair` не можна створити нову пару, обидві компоненти якої незалежно залежать від двох runtime-входів.
- Без `atom-identity` випадки `(a,a)` і `(a,b)` мають однакові unary atom-class observations.
- Без `atom-class` проєкції та identity probes є частковими на різних частинах atom/pair partition; host errors не допускаються як прихований oracle.

## Наслідок

Поточні дані підтримують окремий аналіз value-structure foundation і evaluator/control foundation. `QUOTE` та `COND` не повинні автоматично брати участь у доказі мінімальності алгебри значень.

Наступні питання: чи потрібна саме конкретна `()`, чи лише абстрактний ground-role; і чи evaluator/control можна нашарувати над value algebra.
