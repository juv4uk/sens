# Локальні імена → числові координати: історичний machine-block.lisp

Статус: **вузький виконуваний доказ, не ратифікація і не міграція T5**. Залежності #3135, #3910, #4556, #4650.

Запуск: `python3 scripts/prove_lexical_locals.py --require-machine-block-provenance`.

Інструмент повторно використовує AST-парсер `scripts/migrate-three-pass.py` і читає незмінений original Git blob `200201b741787c4e144ad4194848acf51d7b439e`.
В оригіналі **6 DEFINE/LAMBDA і 7 локальних посилань**. Людські імена параметрів відображено в уже наявні в AST числові `Local(depth,index)`.

| Історичне визначення | Локальні координати |
|---|---|
| machine-block | (0,0) |
| machine-block-empty | немає |
| machine-block-one | (0,0) |
| machine-block-append | (0,0), (0,1) |
| machine-block-concat | (0,0), (0,1) |
| machine-block-forms | (0,0) |

Тести також перевіряють α-еквівалентність, вкладений захват depth>0, лексичне затінення, індекс другого параметра й fail-closed для дубльованих/невідомих змінних, quoted data і нерозпізнаних історичних викликів.

**Це не авторизує фізичне кодування.** Історичні 8-бітні голови LIST/APPEND лишаються історичними викликами, а шість глобальних назв DEFINE — тільки provenance: код НЕ вигадує їм бітів D7/D8 і не торкається доменної семантики. Існуючий `Local(depth,index)` у внутрішній AST не означає, що числовий slot уже має затверджене T5-представлення.

До першої справжньої міграції оригіналу ще потрібні: (1) формальний D2/D7/numeric-local-frame закон для global DEFINE та слотів (#3910/#3135); (2) Rust `sens-trit open/eval` на реально згенерованому same-stem T5, а не наперед упакованому байтовому сурогаті; (3) незалежна дев'ятикейсова історична/current oracle parity, immutable source blob і українська/source/view тотожність.

**Чесна метрика: 6 визначень і 7 локальних посилань розв'язано на рівні лексичної AST; нових доведених фізичних міграцій — 0.**
