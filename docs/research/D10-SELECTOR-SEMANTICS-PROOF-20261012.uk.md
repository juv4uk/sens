# D10: конструктивне семантичне свідчення для 256 селекторів

**Дата:** 2026-10-12. **Гілка:** `main`. Цей документ не переглядає рішення власника про ратифікацію всього D10 (1024/1024).

## Що саме доведено

Сімейство `C[AD]{8}R` складається з **256 різних композицій** `CAR/CDR` над повними двійковими парами глибини 8. Кожен селектор задає шлях із 8 послідовних виборів (читання назви справа наліво). Дерево-свідок має 256 листків з унікальними адресами `A/D`.

- Для кожного з 128 ратифікованих батьківських селекторів D9 існують рівно двоє дітей D10: `A` та `D`, призначення суфікса й точна десятирозрядна координата збігаються з законом `selector-suffix-extension`.
- Для всіх 256 дітей композиція `CAR/CDR` на одному повному дереві збігається з адресним оракулом, який не викликає `CAR/CDR`. Перевірено також `child(x) = parent(CAR(x))` або `parent(CDR(x))` відповідно до бітового суфікса.
- Отримано рівно **256 різних результатів** на цьому свідку. Це конструктивно відрізняє кожну пару селекторів **усередині цього сімейства**: існує один вхід, на якому їхні значення різні.
- Кожна пара координата/ідентичність звіряється з канонічним D10, незалежно від старого дослідного статусу окремих рядків. Вхідні артефакти перевіряються Git-blob SHA; за довільної заміни джерела доказ зупиняється.
- Шість негативних контролів навмисно псують суфікс, батька, координату, ім'я, gauge або live-реєстр. Усі зобов'язані падати, зокрема під `python3 -O`.

## Межі доказу — важливо

Це **конструктивний математичний доказ композиції та попарної відмінності на визначеній області повних дерев-пар**, а не незалежна атестація виконання SENS або всіх 1024 значень D10. Він **не доводить** коректну поведінку на атомі чи порожньому списку, не завершує F1 донорів, F2 незалежного зовнішнього оракула, F3 порівняння з усіма D1–D10 або F4 фізичного T5. Поза сімейством 256 селекторів жодного нового PASS не встановлено.

Власник уже ратифікував **весь каталог D10**. Внутрішні прапорці `ratified_resident=false` є архівними і не переписуються цим доказом. Фізичне виконання залишається fail-closed.

## Відтворення

```sh
python3 scripts/check_d10_selector_semantics_20261012.py --self-test
python3 -O scripts/check_d10_selector_semantics_20261012.py --self-test
```

Автоматичний маршрут: `.github/workflows/d10-selector-semantics-20261012.yml`. Порівняння з двійковим runtime — наступна окрема доказова ланка.

Алгебра підстановки селекторів може перевірятися скінченно на дереві-свідку; для складніших D10 законів використовуємо незалежні еталони, Z3/SMT або Chez/SBCL із відтворюваним протоколом, а не лише зіставлення назв.
