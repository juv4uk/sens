# D10: первісний двійковий блок — повне повторення, а не зсув

Статус 2026-10-09: **selected research** (632/1024), **coordinate=null**, ратифікованих нових D10 = 0. Жодних нових машинних опкодів, D2 структур, файлів `.sens` чи доказів фактичного виконання програми в SENS.

## Математичний закон

Для скінченного слова D1-бітів `w` визначити найкоротший префікс `u`, такий, що **повне** слово складається рівно з `m` цілих копій `u`. Тобто `w=u^m`, `m≥1`. Довжина `u` обов'язково ділить довжину `w`. Для порожнього слова явно прийнято результат порожній.

Історичне / математичне першоджерело: [SageMath — Finite Word, primitive() та primitive_length()](https://doc.sagemath.org/html/en/reference/combinat/sage/combinat/words/finite_word.html). Важливе розрізнення: `minimal_period` дозволяє неповний фінальний фрагмент. Наприклад, `01010` має мінімальний перекривний період `2`, але **первісний блок** тут усе слово `01010`, а не `01`. Це фальсифікаційний тест.

| Слово | Первісний блок | Чому |
|---|---|---|
| `01010101` | `01` | 4 повні копії |
| `101101101` | `101` | 3 повні копії |
| `000000` | `0` | 6 повних копій |
| `01010` | `01010` | `01` не ділить довжину 5 |
| `00100` | `00100` | немає меншого цілого множника |
| `()` як порожні дані | порожня послідовність | нульовий випадок визначено явно |

## Зв'язок із багаторічними напрямами проєкту

Повторювані музичні мотиви, тактові сигнали FPGA/ESP32, періодичні двійкові радіокадри, астрономічні цикли спостереження, хронометрія, санскритські метричні послідовності. Ці області користуються **одним** скінченним законом над даними, а не шістьма різними D10 функціями. Апаратні переривання, частоти, CUDA, драйвери й символьна фонологія лишаються власними субстратами або бібліотеками.

Ратифікований D8 `ROTATE` та `CANONICALIZE` **не надають автоматичного дозволу на дубль**: нове значення повертає найкоротший повний блок **у тій самій орієнтації**, не канонічну ротацію. Перевірка поведінкової незалежності від цих D8 контрактів залишається обов'язковою під час власницького розгляду; похідність від функцій послідовностей сама по собі не дорівнює тотожності, але її треба відзначати.
