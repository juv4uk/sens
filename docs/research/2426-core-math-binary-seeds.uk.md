# #2426 — Мінімальні двійкові насіння та закони в Core-Math

Статус: реалізація дослідження рівня P0.
Базова онтологія: #2490.
Фундамент зростання: #2460 / PR #2636.

Доменний фаєрвол: #2508 / #2509.
Конвергенція: #2495.

## Результат

Турнір необхідності «вилучення одного» (remove-one necessity tournament) для мінімального базису реалізовано мовою Rust із нулем зовнішніх залежностей у каталозі `benchmarks/core-math-binary-seeds/`.

Дослідження дає пряму відповідь на центральний принцип задачі #2426:
```text
Кожне двійкове насіння має заслужити право на існування.
```

### 1. Методологія турніру необхідності
Для кожної кандидатської посилки в базисі $\mathcal{B} = (\mathcal{S}, \mathcal{L})$:
- Система генерує обмежене замикання можливостей $\mathcal{C}(\mathcal{B})$.
- Кандидатська посилка $p$ вилучається, після чого обчислюється зменшене замикання $\mathcal{C}(\mathcal{B} \setminus \{p\})$.
- Різниця можливостей $\Delta\mathcal{C} = \mathcal{C}(\mathcal{B}) \setminus \mathcal{C}(\mathcal{B} \setminus \{p\})$ визначає статус:
  - Якщо $\Delta\mathcal{C} \neq \emptyset$: посилка $p$ є **суворо необхідною**.
  - Якщо $\Delta\mathcal{C} = \emptyset$: посилка $p$ є **надлишковою** і відкидається з мінімального базису.

### 2. Канонічний мінімальний базис (11/11 суворо необхідні)
Оцінений мінімальний базис містить 6 насінин та 5 законів:
- **`Domain::QGroupFactor` (#2494)**:
  - Насіння `0` (адитивний корінь): вилучення втрачає NEG (`00`) та SUB (`01`).
  - Насіння `1` (мультиплікативний корінь): вилучення втрачає RECIP (`10`) та DIV (`11`).
  - Закон `inverse_role` (дельта `0`): вилучення руйнує генерацію обернених операцій.
  - Закон `quotient_role` (дельта `1`): вилучення руйнує генерацію операцій частки.
- **`Domain::SelectorPath` (#2485, #2495)**:
  - Насіння `101` (корінь First): вилучення руйнує дерево шляхів CAR.
  - Насіння `110` (корінь Rest): вилучення руйнує дерево шляхів CDR.
  - Закон `extend_zero` (дельта `0`): вилучення руйнує проекції First.
  - Закон `extend_one` (дельта `1`): вилучення руйнує проекції Rest.
- **`Domain::AffineFunctionGF2` (#2319)**:
  - Насіння `100111` (Інверсія): вилучення руйнує операцію NOT та непарні перетворення.
  - Насіння `011000` (Транспозиція): вилучення руйнує перестановку координат.
  - Закон `composition`: вилучення руйнує всю алгебру складених функцій.

### 3. Теорема про одиничне насіння
Ключовий математичний результат турніру:
В групі $\mathrm{AGL}(2,2)$ одинична функція (`100100`) виводиться з квадрата будь-якої інволюції:
$$\mathrm{Inversion} \circ \mathrm{Inversion} = \mathrm{Identity}$$
$$\mathrm{Swap} \circ \mathrm{Swap} = \mathrm{Identity}$$
Отже, утримання одиниці як аксіоматичного насіння в базисі з інверсією або транспозицією є **надлишковим**. Одиниця заробляє своє існування як доведена теорема, скорочуючи кількість первинних аксіом.

### 4. Фальсифікатори надлишковості
Бенчмарк запускає два обов'язкових негативних контроли:
1. **Похідне насіння**: Додавання `1010` у базис провалює тест вилучення ($\Delta\mathcal{C} = \emptyset$) $\implies$ правильно маркується як надлишкове.
2. **Одинична координата**: Додавання `100100` у базис провалює тест вилучення ($\Delta\mathcal{C} = \emptyset$) $\implies$ правильно маркується як надлишкове.
