# #2441 — історична семантика SET/SETQ у Lisp 1.5

Статус: дослідницький доказ для Phase D.

Первинне джерело: *LISP 1.5 Programmer's Manual*, MIT Press, 1962.

Джерело:
https://softwarepreservation.computerhistory.org/LISP/book/LISP%201.5%20Programmers%20Manual.pdf

## Результат

Історична семантика інтерпретатора збігається з нижньою межею #2402:

```text
HISTORICAL-SETQ=SHARED-LOCATION-UPDATE
```

Appendix B описує SET/SETQ так:

1. ім'я змінної шукається в поточному a-list;
2. value-cell вже існуючої binding-пари замінюється новим значенням;
3. якщо ім'я зв'язане кілька разів, змінюється перше / найсвіжіше входження;
4. якщо binding належить вищому рівню, нове значення діє до кінця scope цього binding;
5. якщо імені немає — A4/A5, а не створення нового binding.

Розділ про PROG також прямо каже, що SET/SETQ можуть змінювати змінні в a-list функцій вищого рівня.

## SET проти SETQ

Мутаційний механізм той самий:

```text
SET   : перший аргумент обчислюється і дає ім'я змінної
SETQ  : перший аргумент автоматично quote
```

Значенням обох форм є значення другого аргументу.

## Порівняння з #2402

```text
нижня межа #2402                    Lisp 1.5
---------------------------------------------------------
оновити існуючу location            так
найближчий існуючий binding         так: перший / найсвіжіший
не створювати binding при miss      так: A4/A5
вищий observer бачить update        так у scope цього binding
computed target vs syntax-fixed     SET vs SETQ
```

## Важлива межа

Історичний носій — динамічний a-list binding pair.

Не можна підміняти це твердженням:

```text
Lisp 1.5 вимагав сучасну lexical closure cell
```

Первинне джерело доводить вужче потрібне твердження:

```text
мутується та сама вже існуюча binding-пара,
і подальший lookup через цей binding бачить нове значення
```

Отже #2402 правильно знайшов історичну форму lower bound. Але це ще не доводить нову SENS-capability: #2442 має атакувати її чистим D4 state-passing без прихованої host mutation.

Жодної адреси або ширини цей результат не призначає.
