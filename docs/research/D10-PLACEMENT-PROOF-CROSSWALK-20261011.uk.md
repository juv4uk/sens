# D10: перенесення вже доведених координат у доказову карту

**Дата:** 2026-10-11. **Контракт:** 11.8. **Стан:** лише дослідження; D10 не ратифіковано.

Цей звіт не припускає, що кожному обраному значенню вже доведено координату. Це суворе перехресне звіряння трьох дійсних джерел:

- `knowledge/d9-ratified.json` — нормативна D9 512/512, рішення власника #4008.
- `knowledge/d10-selector-seed.json` — 128 математично доведених D9 selector-батьків та два дочірні значення `p0` і `p1`.
- `knowledge/d10-v1-semantic-inventory.json` — єдиний чинний дослідницький реєстр D10. Стан на початку перевірки: **653/1024 selected; 256 координованих, 397 обраних без координати, 371 без обраної семантики, 0 ратифікованих**.

## Доказ розміщення

Для кожного доведеного селектора D9 `p`, закону `p0 = compose CAR/A` і `p1 = compose CDR/D` однозначно відповідають дві 10-бітні координати. Це **змістовний закон генерації**, не самовільне подвоєння усіх 512 значень D9. Перевірка також зіставляє `stable_id`, батьківську семантику, bit suffix, точну координату й дійсну координату в канонічному D10. Жодну координату для інших 397 рядків не домислювати.

Негативні контрольні мутації: батько, суфікс, семантика, розміщення, колізія, несанкціонована ратифікація, вилучений resident, підроблений лічильник і parent-gauge. Кожну необхідно відхилити. Python `-O` **не має права** вимкнути `require`.

```sh
python3 scripts/check_d10_placement_proof_crosswalk.py --self-test \
  --manifest /tmp/d10-placement-crosswalk.json
python3 -O scripts/check_d10_placement_proof_crosswalk.py --self-test
```

Вихідний JSON є **доказовою перехресною картою**, не другою семантичною владою. Він дозволяє автоматично знайти 397 поточних непоставлених значень і при майбутньому наповненні покаже дійсну кількість після кожного append.

## Наступний етап — вже готові історичні докази

Кожен історичний аргумент щодо D10 треба класифікувати окремо:

1. **PLACED-BY-LAW:** координата точно відтворюється з чинного ратифікованого батька й незалежної теореми; не повторюємо оригінальні 256 доказів.
2. **SEMANTIC-WITNESS:** доказ поведінки/оракул є, але адреса не випливає з нього. Такий рядок можна зберігати як обраний без координати.
3. **HISTORICAL-ADDRESS:** колишній SID, D8/D9, старий код або просте історичне ім'я не є новою координатною владою.
4. **HOLD:** колізія, суперечливе джерело, unresolved Core-vs-derived або відсутня незалежна теорема розміщення — жодної тихої ратифікації.

Архіви й готові донори: #5131 (вся історія), #5540 (87 owner repositories), #5539 (source audit), #4013 (інвентар), #5041 (single-writer). Поки чинна історія в `main` має перевірений source-tail конфлікт на transitions 651→652 і 652→653, `main` **не оголошувати готовим до наступних семантичних злиттів** без коректного provenance repair та зеленого exact-head CI.

**Критерій D11:** 1024 різні значення, 1024 коректно доказово розміщених, окрема ратифікація власника; жоден інструмент із цього PR не здійснює її.
