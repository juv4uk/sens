# D10 — Символьний ШІ: найменше загальне узагальнення термів

**2026-10-09 · дослідження · 0 нових SELECTED · 0 координат · 0 ратифікацій.**

Мета — продовжити початковий курс SENS на **Advice Taker**, Lisp-машину та логічний висновок. Тут потрібен закон, як машина може вчитися на прикладах, утворюючи **спільний шаблон знань**, не змішуючи це з `UNIFY` чи зі статистичним навчанням.

## Донор

У [SWI-Prolog — бібліотека термів](https://www.swi-prolog.org/pldoc/man?section=terms) є `term_subsumer(+Special1,+Special2,-General)`: найбільш специфічне узагальнення двох заданих термів. Суміжний проєкт — [anti_unify/3](https://www.swi-prolog.org/pack/list?p=anti_unify).

Запропонована D10-назва **`FINITE-TERM-ANTI-UNIFY`**, українські поверхні: **`узагальнити-терми`** (ук), **`найменше-спільне-узагальнення-термів`** (укр). Контракт спеціально обмежений **скінченними ациклічними повністю конкретними термами першого порядку**; не заявляємо підтримки циклічних Prolog-термів, attributed variables, вільних змінних у вході чи side effects.

Для входів `A`, `B` отримати `G` та дві підстановки `σA`, `σB`, такі, що `G[σA]=A`, `G[σB]=B`. Однакові константи й однакові функтори з тотожною арністю зберігаються. Кожна різна пара підтермів отримує нову змінну; **одна й та сама впорядкована пара неоднакових підтермів у різних місцях отримує ту саму змінну**.

| Перший терм | Другий терм | Найменше узагальнення |
|---|---|---|
| `pair(a,a)` | `pair(b,b)` | `pair(V0,V0)` |
| `pair(a,a)` | `pair(b,c)` | `pair(V0,V1)` |
| `parent(ann,leo)` | `parent(ann,mira)` | `parent(ann,V0)` |
| `f(g(a),g(a))` | `f(g(b),g(b))` | `f(g(V0),g(V0))` |
| `f(a)` | `g(a)` | `V0` |

**Негативний закон:** `pair(V0,V1)` для `pair(a,a)` і `pair(b,b)` *надто загальне* — втрачено вимогу рівності обох позицій. Натомість `pair(V0,V0)` для `pair(a,a)` і `pair(b,c)` взагалі не має необхідної підстановки для другого входу. Універсальний `UNIFY` D1–D9 має **протилежний напрямок** (знайти підстановки для зрівнювання), отже його ім'я та відома поведінка не дають автоматичної тотожності.

## Звідки взяті ідеї

- **Advice Taker, Lisp, Prolog, символьний ШІ:** узагальнення повторюваних правил та AST, передусім як чистий оператор дослідної бібліотеки.
- **Санскрит і Паніні:** спільні шаблони фонологічних/граматичних структур, але не дубль вже досліджених `RESOLVE-PRATYAHARA`.
- **Астрономія:** індукція однакових структур подій спостережень за різних об'єктів та умов.
- **SDR, FPGA та радіоелектроніка:** узагальнення структури станів/подій, а не механізму радіомодулятора, DMA чи машинного опкоду.
- **Музика:** спільні дерева мотивів і структур ритму, окремо від самого звукового синтезу.
