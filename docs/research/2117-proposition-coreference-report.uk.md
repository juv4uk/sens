# #2117 — кореференція тверджень нижче за статус факту

Лише дослідження. Жодної production-міграції.

## Свідок

Беремо ті самі три входження доказів:

```text
e1 : підтримка
e2 : спростування
e3 : підтримка
```

Змінюємо лише те, які входження вважаються такими, що стосуються **того самого твердження**.

### Модель A
```text
{e1,e2} -> BOTH / конфлікт
{e3}    -> підтримано
```

### Модель B
```text
{e1,e3} -> підтримано
{e2}    -> спростовано
```

### Модель C
```text
{e1} -> підтримано
{e2} -> спростовано
{e3} -> підтримано
```

Потік входжень і їхні знаки підтримки/спростування в усіх трьох моделях однакові.

Отже статус твердження — підтримано, спростовано чи конфлікт — не визначається самим потоком evidence. Потрібен окремий закон або свідчення **кореференції**, який визначає, які входження говорять про те саме твердження.

## Наслідок

Шар `ADMITTED/REFUTED/UNKNOWN` з #2112 вже припускає нижчий шар ідентичності/кореференції тверджень.

Цей шар не можна непомітно визначати через:
- рівність host-рядків;
- тотожність рядка таблиці;
- місце у файлі;
- overwrite-поведінку;
- інші механічні координати.

Для такого ототожнення потрібна окрема теорема збереження смислу.

## Відкрите питання

Цей witness ще не доводить, що кореференція обов’язково має бути повним відношенням еквівалентності.

Залишаються відкритими:
- часткова кореференція;
- контекстно залежна кореференція;
- неоднозначна кореференція;
- правила, за якими окремі evidence-occurrence можна об’єднувати в один proposition-клас.

## Принцип

**Перш ніж визначати істиннісний або епістемічний статус твердження, треба обґрунтувати, які шматки evidence взагалі стосуються того самого твердження.**
