# D10: міждисциплінарні семантичні закони для SENS

Дата: 2026-10-09. Координація: #4013, #4463.
Статус: **RESEARCH / SELECTED-BUT-UNPLACED / NOT-RATIFIED**.

## Навіщо

Ідеї для функцій черпаємо зі спільних тем: астрономія й астрофізика, аналогові обчислення, метрологія, математика, радіо/SDR, акустика та музика, ESP32/FPGA, електроніка, програмування Lisp і WSM-OS-LISP, санскрит і фонологія. Інтерес — привід для пошуку математично чітких законів, але НЕ заміна перевірки на дублювання.

| Дослідницька функція | Інтуїтивне українське ім'я | Інваріант | Інституційне джерело |
|---|---|---|---|
| COVARIANCE-TRANSPORT | перенести-коваріацію | JΣJᵀ, із кореляціями | NIST GUM |
| FRAME-STATE-TRANSFORM | перенести-положення-та-швидкість | p'=Rp, v'=Rv+Ṙp | NASA NAIF SPICE |
| RATIONAL-RESAMPLE | змінити-частоту-відліків | fs' = fs·L/M, причинний FIR, збереження фази потоку | GNU Radio |

**Це три похідні, але поведінково чіткі й перевірювані дослідницькі значення**, а не нові математичні аксіоми чи CPU інструкції. Саме тому жоден код не має D10 координати, а виконання перевіряється окремими еталонними моделями на Python, не вигаданим виконанням SENS. Мовні структури та керування лишаються виключно за D2.

### Контрприклади

- **Коваріація:** заміна Σ тільки діагональними дисперсіями губить кореляцію. Для Σ=[[4,2],[2,9]], J=[[1,1],[1,-1]] результат [[17,-5],[-5,9]], не [[13,-5],[-5,13]].
- **Рухома система координат:** звичайний ROTATE переносить позицію, але без похідної Ṙ втрачає швидкість, породжену обертанням осей.
- **Передискретизація:** множення частоти без належного FIR змінює фізичні дані (aliasing/images); перезапуск фази на межі блоку порушує інваріант неперервного потоку.

### Вісім ідей НЕ відбираємо без окремого доказу

FOURIER-TRANSFORM, PHASE-UNWRAP, SATURATING-ADD, TIME-SCALE-CONVERT, PANINI-PHONEME-TRANSDUCE, OSCILLATOR-PHASE-STEP, ADC-QUANTIZE, CRC-UPDATE. У більшості з них уже є арифметичний, D6 SCAN, D7 phoneme чи D10 Panini фундамент, або потрібні зовнішні часові таблиці; вони залишаються у списку HOLD, а не займають координати. Особливо не змішувати бітовий транспорт і D2 структуру мови.
