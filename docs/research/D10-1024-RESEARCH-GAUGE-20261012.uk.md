# D10 — повна дослідницька карта 1024 кодів (не ратифікація)

12.10.2026. D10 має **1024/1024 дослідницьких семантичних описів**. Це ще не означає 1024 доведені незалежні закони чи надане право фізичного виконання.

## Призначення адрес

Вхідний Git blob: knowledge/d10-v17-semantic-inventory.json (SHA у маніфесті).

Файл knowledge/d10-v17-complete-research-gauge-20261012.json має рівно **1024 пари stable_id → 10-бітний код**:

- **719** наявних координат збережено без змін.
- **305** раніше порожніх координат отримали найменші вільні 10-бітні слова у вихідному порядку кандидатів.
- Всі коди від 0000000000 до 1111111111 зайняті рівно по одному разу — у дослідницькій пропозиції.
- **Канонічний inventory та canonical_current не переписано**. Це окремий research-only gauge, не виконувана ISA.
- Ні ратифікація, ні фізичне виконання D10/T5 не дозволені цим розміщенням.

В останньому v17 додано 54 авторські математичні пропозиції без незалежного донорського запуску, виконаних позитивних і негативних оракулів і доказів семантичної нетотожності. Заповнення карти не додає цим законам F1/F2/F3 PASS.

## Перевірка

Команда: python3 scripts/check_d10_v17_complete_research_gauge.py --self-test

Перевірка фіксує Git blob, точно 1024 ідентичності, 719 незмінних координат, порядок 305 нових, бієкцію всіх 1024 кодів, нуль ратифікацій і нуль дозволів виконання. Вона також відхиляє 7 негативних мутацій.

Нова canonical версія потребує окремого перенесення адрес після перевірки всіх законів. Ратифікація всього D10 — окреме рішення після завершення перевірок.
