# D10: порівняння кривих із WSM-24 — точний закон, не поспішний опкод

2026-10-09 · координація #4013, #4463, #4908.

## Донор, який реально існує

У `juv4uk/WSM-24` є [Clojure-реалізація геометрії](https://github.com/juv4uk/WSM-24/blob/aa78f6ccf740dbb7555f46eeaba9cb970ee7a87f/src/egg/compare.clj), exact Git blob `6a5b004f1fddaa763a94328ad0aa654053279faf`. Вона порівнює нормалізовані та ресемпльовані криві космічного/екліптичного візуалізатора, а не незмінні порядкові відповідності точок. Її `chamfer` використовує **звичайну евклідову відстань із hypot/коренем**, не квадрати довжин. Окремі [Clojure тести](https://github.com/juv4uk/WSM-24/blob/aa78f6ccf740dbb7555f46eeaba9cb970ee7a87f/test/egg/compare_test.clj) Git blob `ab0765adffbb924735e567d35bb19d09bcf83eec` перевіряють порівняння з поворотом та масштабом після нормалізації.

Наш **НОВИЙ ДОСЛІДНИЦЬКИЙ варіант** використовує інший закон — точний квадрат евклідової відстані над раціональними координатами, **без плаваючої арифметики та без квадратного кореня**. Не видаємо ці два результати за чисельно тотожні.

Загальна сім'я Chamfer із направленими середніми і squared-L2 варіантом наведена в [Wolfram MathWorld](https://mathworld.wolfram.com/ChamferDistance.html) та [NVIDIA Kaolin](https://kaolin.readthedocs.io/en/v0.12.0/modules/kaolin.metrics.pointcloud.html).

## Кандидат

`EXACT-SYMMETRIC-SQUARED-CHAMFER`, українські поверхні в `knowledge/d10-wsm24-exact-chamfer-hobbies-v1.json`. Для непорожніх масивів раціональних точок однієї розмірності

[
C_2(A,B)=\frac{1}{2}\left(\frac{1}{|A|}\sum_{a\in A}\min_{b\in B}\|a-b\|^2
+\frac{1}{|B|}\sum_{b\in B}\min_{a\in A}\|b-a\|^2\right).
]

Результат: точний score і два масиви індексів найближчих точок. При рівності відстаней обирати **перший індекс** іншої хмари; повторювані точки враховуються стільки разів, скільки вони зустрілись у вхідному масиві. Порожню хмару, невідповідні виміри, `float` або булеві координати відхиляти, не мовчки апроксимувати.

Фальсифікатори:
- A=[0,2], B=[0] → score=1; односторонній результат дасть інше.
- A=[0,0,2], B=[0] → 2/3; множинна дедуплікація помилково змінить score.
- A=[0], B=[-1,+1] → рівність і вибір B[0], не B[1].
- Не називати функцію метричним простором: singleton 0,1,2 порушує нерівність трикутника (4 більше від 1+1).
- Не називати її апріорі інваріантною щодо **нормалізації чи повороту лише однієї хмари**. Натомість доводимо інваріантність під одночасними переносами/жорсткими поворотами **обох** хмар.

## Доказ

`tests/test_d10_wsm24_exact_chamfer.py` використовує `fractions.Fraction`, два незалежні шляхи обчислення: направлений пошук з першою tie-позицією та повну all-pairs матрицю; 24 025 впорядкованих пар хмар 1D, свідки дробових 2D, симетрію, невід'ємність, перенос, 90° поворот, ненормативну трикутну нерівність, помилкові домени. Окремо 8 негативних мутацій доказів відхиляють підроблене джерело, зміну моделі, фальшиву ратифікацію й відсутність фальсифікаторів.

Це **модельна точна перевірка**, не запуск SENS binary-коду і не claim Clojure-vs-SENS runtime parity.
