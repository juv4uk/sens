# #2019 — first bīja3 pressure diagnostic

Research-only. This is deliberately weaker than a minimality proof.

## Question

If one inherited bīja3 seed is removed from the **current declared Lisp I / Lisp
1.5 dependency corpus**, how much derived material currently depends on it?

This answers a corpus-coverage question only.

It does **not** answer:

- whether the seed is logically necessary;
- whether the seed can be reconstructed by an undiscovered law;
- whether another basis would be smaller;
- whether bīja3 is unique.

## Why this diagnostic exists

Before attempting alternative bases, we need to know where the current corpus
puts pressure.

A high-pressure root deserves a stronger replacement proof if removed.

A low-pressure root is not automatically removable.

## Metrics

For each seed and era:

- number of derived nodes whose transitive seed-support includes it;
- number of descendants supported exclusively by that seed;
- number of co-seeds appearing with it;
- whether the declared graph already contains a path from that seed to another
  seed.

The last field is only a graph diagnostic, not independence proof.

## Positive control

CAR/CDR should have exclusive selector descendants in the bounded corpus.
The script asserts this.
