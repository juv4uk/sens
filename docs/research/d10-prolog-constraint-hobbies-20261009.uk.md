# D10: три значеннєві кандидати з Prolog, Advice Taker та граматики Паніні

Це **дослідження, а не ратифікація чи нові двійкові коди**. На початку головний D10 мав **630/1024 selected, 0 ratified**. Ці три результати — `HOLD`: без координат, без зміни ратифікованих D1–D9, D2 чи фізичного T5.

| Пропозиція | `ук` / `укр` | Видимий закон | Чому не дубль простої перевірки |
|---|---|---|---|
| `UNIFY-WITH-OCCURS-CHECK` | `узц` / `узгодь-без-циклу` | Уніфікація скінченних термів, яка забороняє прив'язати змінну до терма, що містить її саму. | Не тотожна перевірці рівності, співставленню фактів або відображенню підстановок. |
| `DELAYED-TERM-DISEQUALITY` | `внр` / `відкладена-нерівність` | Постійне обмеження `dif(X,a)`: X ще може бути вільною, але майбутнє X=a не допускається. | Не дорівнює одноразовій нерівності чи D1-біту. |
| `COPY-RESIDUAL-CONSTRAINTS` | `коб` / `копія-з-обмеженнями` | Копіювання терма з явним списком відкладених умов та відтворенням цих умов у копії. | Не тотожне `copy_term` без відновлення обмежень. |

## Як це пов'язано з проєктом

**Advice Taker, логічне доведення, Prolog:** sound unification не дозволяє створювати циклічні хибні докази. **Санскрит/Паніні:** відкладена нерівність допомагає відстежувати несумісні граматичні властивості без передчасних рішень. **Самохостинг SENS:** явний список обмежень — кандидат на представлення стану пошуку як значення; не сам по собі opcode процесора.

Інші захоплення вже мають паралельні напрями: астрономія/час → #4889/#4890; радіо, SDR, акустика → #4888/#4890; FPGA/ESP32 — carrier-specific регістри не D10; раціональні наближення → #4891/#4892; шахи/графи → 52-кандидатний огляд #4013. Усі ідеї зберігаються в єдиному потоці D10, не в окремих «фізичних доменах».

## Точний стан доказів

- **Донор:** [SWI `unify_with_occurs_check/2`](https://www.swi-prolog.org/pldoc/man?predicate=unify_with_occurs_check%2F2) (ISO), [`dif/2`](https://www.swi-prolog.org/pldoc/man?predicate=dif%2F2) (відкладені обмеження), [`copy_term/3`](https://www.swi-prolog.org/pldoc/man?predicate=copy_term%2F3) (цілісні зв'язки й residual goals). `dif/2` та форма attributed-variable копіювання тут специфічні для SWI, не проголошені ISO.
- **Машинні докази:** `tests/d10_prolog_constraint_oracle.pl` запускається **справжнім SWI-Prolog** в CI, 13 визначених істинних/негативних witness; `scripts/check_d10_prolog_constraint_hobbies.py` валідує поточний інвентар, surfaces, provenance, недопуск, 12 adverse mutation checks і точний список run-case ID.
- **Поки не доведено:** повна поведінкова дедуплікація D1–D9/D10 (перевірена тільки відсутність точних нових назв у D10 630), незалежний другий реалізатор, власник Core vs selfhost library, виконавчий оракул самого SENS. Немає доведеного заблокованого старого `.lisp` для цих функцій; `blocked_original_source=null`, не вигадуємо його.
- **До вибору в inventory:** #4902 proposal-ledger/growth gate, власникове семантичне рішення, source revision pin або документоване виключення для первинної онлайн-специфікації. Усі `coordinate=null`, `ratified=false` і нових `selected=0`.

Залежить від #4013, #4463, #4896. Матеріал — для одночасної перевірки агентами з питань логіки, компілятора та Паніні, не для прямого merge в реліз.
