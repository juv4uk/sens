# D10: символьний ШІ — однобічне охоплення терма

**Стан 2026-10-09: RESEARCH / HOLD. Нових SELECTED 0, координат 0, ратифікацій D10 0.**

## Чому це окремий закон

Нова кандидатна ідентичність: **`FINITE-TERM-SUBSUMES`**. Українські поверхні `охоплює-терм?` (ук) та `чи-загальний-терм-охоплює-конкретний?` (укр).

**Донор:** [SWI-Prolog subsumes_term/2](https://www.swi-prolog.org/pldoc/man?predicate=subsumes_term%2F2). Задано два скінченні ациклічні терми першого порядку `P` (шаблон, Generic) та `S` (приклад, Specific), причому простори змінних відокремлені. Результат **YES** тоді й лише тоді, коли існує підстановка **лише для змінних P**, така, що `σ(P)=S` структурно (з точною арністю і тотожністю змінних S). Якщо YES — дозволено повернути саму підстановку як **незмінні дані**. При NO жодна часткова підстановка не виходить. Жоден початковий терм не змінюється.

Це **не симетрична уніфікація**. Наприклад, симетричне `UNIFY(f(a,P0), f(S0,b))` може зв'язати `S0=a`, однак `FINITE-TERM-SUBSUMES` мусить повернути **NO**: змінна `S0` належить конкретному терму, її прив'язка заборонена.

| Загальний P | Конкретний S | Результат |
|---|---|---|
| `f(P0,P0)` | `f(a,a)` | YES, `P0=a` |
| `f(P0,P0)` | `f(a,b)` | NO |
| `f(P0,P0)` | `f(S0,S0)` | YES, `P0=S0` |
| `f(P0,P0)` | `f(S0,b)` | NO |
| `f(a,P0)` | `f(S0,b)` | NO, не змінювати `S0` |
| `f(P0,g(P0))` | `f(a,g(a))` | YES |
| `f(P0,P1)` | `f(S0,S0)` | YES, обидва можуть означати S0 |
| `f(a)` | `f(a,b)` | NO — інша арність |

На відміну від **антиуніфікації**, яку одночасно дослідили агенти #4970 та #4973, ця функція **не шукає найменше загальне узагальнення двох прикладів**. Вона вирішує, чи вже заданий шаблон охоплює приклад. Тому не можна зараховувати #4970, #4972 і #4973 як три окремі значення; мій дубль #4972 закритий, тестові докази збережені для рецензування.

## Чому це корисно нашому проєкту

- **Advice Taker, Lisp-машина, Prolog:** добір релевантних правил, перевірка форми фактів без прихованого зв'язування знань.
- **Санскрит / Паніні:** чи підходить звуковий або граматичний терм під задану структурну схему.
- **Астрономія:** перевірка однакових структур записів вимірювання при різних приладах.
- **SDR та FPGA:** порівняння протокольних дерев подій, а не драйверів чи синхронізації фізичного каналу.
- **Символьний ШІ загалом:** перевірка застосовності гіпотези перед побудовою пояснення та доведення.

## Межі й докази

`tests/d10_finite_subsumes_swi.pl`: **реальний SWI-Prolog**, перевіряє `subsumes_term/2` на одно- й двосторонніх випадках, а також відсутність прив'язування обох джерельних термів. `tests/test_d10_finite_subsumes.py`: незалежна чиста реалізація через однобічну таблицю підстановок, звірка з повним перебором можливих підстановок у **576 парах** скінченних термів, повторні змінні та арність. `scripts/check_d10_finite_subsumes.py`: live dedup D1–D10 і **10 негативних мутацій** статусу й provenance.

Дані P/S не дорівнюють змінним керування D2, мова по замовчуванню двійкова; тут наведено лише людські поверхневі назви для огляду. Підтримка циклічних термів, attributed constraints, unbounded higher-order match та змін в OS/FPGA не заявлена.

**Core vs library — відкрите питання**: навіть доведена функція може бути реалізована як самохостингова бібліотека з `UNIFY`, копіюванням і аналізом термів.
