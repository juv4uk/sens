# D6 v2 law-first ledger — #3333

D6 лишається **UNRATIFIED / RESEARCH**. Цей ledger спирається лише на ратифікований фундамент D1–D5 #3331.

Поточний машинний результат:

```text
місткість                  64
доведені selector rows     16
кандидати з законами       16
UNKNOWN                    32
```

16 селекторів мають placement через рекурсивний selector-generator. Ще 16 рядків мають незалежні семантичні закони, але їхня геометрія лишається саме такою, як каже evidence (`RELATION-ONLY`, `PRODUCT-AXIS-CANDIDATE` тощо).

Інші 32 координати залишаються UNKNOWN. Старі D6-назви збережені лише у полі `donor`, щоб їх можна було перевіряти без автоматичного admission.

Перші кандидати на відсів/атаку:

```text
RPLACA
RPLACD
NCONC
NREVERSE
SETF
```

Вони залежать від мутації/place-семантики, яку сучасний SENS має показати як спостережувану, перш ніж така відмінність отримає D6 identity.

Ціль: щільний D6 64/64 лише якщо всі 64 значення різні, корисні та підкріплені законами.
