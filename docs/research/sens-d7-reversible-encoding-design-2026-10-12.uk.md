# D7: дизайн оборотного кодування на всіх поверхнях (мовах)

Дата: 2026-10-12 · Репо `juv4uk/sens` @ `bf91ea7` · асистент · **пропозиція, не ратифікація**

## 0. Вимога

Точна **7-бітна координата** — це ідентичність. Символ (гліф) — лише *проєкція*.
Щоб кодування було **оборотним на кожній мові**, для кожної поверхні S відображення
`координата ↔ символ` мусить бути **бієкцією**: (1) повне — символ є в КОЖНОГО
резидента; (2) без колізій — два резиденти не ділять один символ. Тоді `symbol→coord`
завжди відновлюється.

## 3. Пропонований дизайн: композиційний символ

Прямі гліфи лишаються для тих, хто їх має. Для решти вводимо **композиційний закон** —
символ *будується* з базового гліфа + модифікатора, тож він існує завжди й лишається
унікальним:

- **Носова голосна = ротовий гліф + знак назальності.** Напр. `a→ã`, `i→ĩ`, `u→ũ`,
  `ṛ→ṛ̃`, `ḷ→ḷ̃`, `e→ẽ`, `o→õ`; довга = відповідний довгий гліф + той самий знак
  (`ā→ā̃`…). Це дає 14 відсутніх клітинок, кожна відмінна від свого ротового предка.
- **Модифікатор = комбінований знак** із власним ім'ям (напр. `◌́` для наголосу,
  окремий знак «велика наступна літера»).
- **Керуючий = іменований ескейп** (напр. `␊` newline, `␉` tab, `␣`-варіант для лапок).

Інваріант, який робить це оборотним: **у межах однієї поверхні кожен символ унікальний**, і
композиція ніколи не збігається з прямим гліфом іншої клітинки.

## 4. Свідок оборотності (fail-closed)

Для кожної поверхні — тест `symbol → coord → symbol` по всіх 126 резидентах:

```
для кожної поверхні S:
    map = { coord: symbol_S(coord) }        # 126 записів, має бути без None
    assert len(set(map.values())) == 126     # без колізій
    for coord, sym in map.items():
        assert inverse_S[sym] == coord       # оборотність
```

Колізія або `None` = **FAIL**, а не «майже добре». Це той самий fail-closed, що вже
використовує репо.

## 5. Чесні межі

- Композиційні символи (`ã`, `␊`…) — **пропозиція**, не ратифіковані; вибір знака —
  рішення власника.
- `en` у `d7.lisp` лишається назвою резидента (контракт валідатора) — тож «поверхня en»
  для *гліфа* — це окрема проєкція, а не колонка `en`.
- Дизайн не змінює жодного файла репо; це проєкт на ратифікацію.
