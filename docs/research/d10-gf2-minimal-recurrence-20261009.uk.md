# D10: мінімальна лінійна рекуренція над двійковим полем

**9 жовтня 2026. Дослідження: 0 нових ратифікованих функцій.**

Нова кандидатна семантика `BINARY-LFSR-MINIMAL-RECURRENCE`. Українська поверхня: `найкоротша-двійкова-рекуренція`; скорочена: `мін-лін-рекур`.

Ідея об’єднує радіо/SDR, FPGA, ESP32, електроніку, ритми музики, математику, структури послідовностей Паніні та двійкову мову SENS. Абстрактна функція не потребує фізичного SDR, генератора або драйвера.

## Контракт

Вхід — скінченна впорядкована послідовність бітів `s`. Знайти найменший порядок `L` так, щоб кожен спостережуваний біт від позиції L задовольняв `s[t] = XOR(a[j] AND s[t-j-1])` для j від 0 до L-1. Із коефіцієнтів, які відповідають найменшому L, вибрати лексикографічно найменший, де 0 перед 1. Результат — порядок і коефіцієнти.

Приклади: порожнє слово -> (0,[]); `11111` -> (1,[1]); `010101` -> (2,[0,1]); `101001` -> (3,[1,0,1]); `11010110010001111010` -> (4,[1,0,0,1]).

Це не синонім `PRIMITIVE-BINARY-WORD-ROOT`: повторюваний блок і мінімальна лінійна рекуренція мають іншу семантику. Також не дублює відбитий код Грея чи одноразове XOR. Але Core проти похідної математичної бібліотеки потребує окремого огляду. Жодної заяви про достовірне прогнозування шумного радіосигналу або криптостійкість.
