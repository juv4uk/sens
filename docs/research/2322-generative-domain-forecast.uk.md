# Прогноз генеративного домену — #2322

Цей дослідницький witness узагальнює вже допущений selector-generator із
D5-only доказу до обмеженого облікового sweep D3→D8.

Він не вигадує функції D6/D7/D8. Він питає лише, що випливає з уже
допущених фактів родини CAR/CDR:

- корені 101 і 110;
- суфікс 0 означає compose CAR;
- суфікс 1 означає compose CDR.

Відтворення:

    python3 scripts/research-2322-generative-domain-forecast.py \
      --min-width 3 --max-width 8 \
      --out /tmp/generative-domain-forecast

Очікуваний інваріант:

    selector_owned(Dn) = 2^(n-2)
    capacity(Dn)       = 2^n
    selector_share     = 1/4

Отже selector-family подвоюється з кожним доданим бітом, але зберігає
постійну частку — одну чверть exact-width координатного простору.

Сенс не в тому, що чверть кожного майбутнього домену треба автоматично
зайняти. Сенс у тому, що ці selector-координати вже не потребують нового
незалежного семантичного винаходу після допуску моделі root+law.

## Межа обліку

Скрипт звітує unexplained_coordinates, а не «нові функції».

Непояснені координати пізніше можуть виявитися:
- справжнім незалежним residue;
- породженими іншим незалежно доведеним законом;
- навмисно незайнятими;
- недопустимими у сильнішій майбутній граматиці.

Тому цей witness не є владою для allocation.

## Зв'язок із function algebra

Це позитивний контроль для:
- #2239 function algebra;
- #2243 generative compression;
- #2321 candidate-law miner;
- #2323 generation certificates.

Наступний корисний результат — не ще один вручну заповнений домен, а більше
замикання, де додаткові родини функцій реконструюються з малого базису
коренів і законів.
