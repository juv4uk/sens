# Прогноз selector-family за Contract 11.6 — #2322 / #3281

Цей witness є чинним позитивним контролем для родини CAR/CDR.

Він більше не моделює D3→D8 як безперервну однобітну семантичну драбину.

Поточна влада:

```text
D3-D6  чинна selector-семантика
D7     чинний домен Sound7/Text7
D8     research / нератифікований
```

Чинні корені D3 за #3202:

```text
011 CDR
100 CAR
```

Для D4-D6 допущений selector-law додає один біт вибору:

```text
0 = compose CAR
1 = compose CDR
```

Отримуємо рівно:

```text
D3  2 selectors
D4  4 selectors
D5  8 selectors
D6 16 selectors
```

## Межа D7

D7 не є selector-сходинкою. За #3572 він володіє семантикою Sound7/Text7.
Тому цей witness показує нуль selector-резидентів у D7 і ніколи не трактує
7-бітне слово як selector-батька лише через його ширину.

## Clean-room кандидат D8

D8 залишається research за Contract 11.6 / #3281.

Тут перевіряється обмежена гіпотеза прямого двокрокового продовження:

```text
чинний D6 selector × W2
        ↓
64 точні 8-бітні координати-кандидати D8
```

Кожен чинний D6 selector отримує чотири двобітні суфікси вибору
`00 01 10 11`. Це дає 64 унікальні D8 координати.

Як незалежна перевірка координат, цей набір дорівнює розгортанню чинних
D3-коренів п'ятьма selector-бітами. Така рівність **не** вводить семантичного
походження через D7; це лише другий спосіб перелічити ті самі бітові рядки.

Відтворення:

```sh
python3 scripts/research-2322-generative-domain-forecast.py \
  --min-width 3 --max-width 8 \
  --out /tmp/generative-domain-forecast
```

Очікуваний облік:

| домен | selector-координати | статус |
|---|---:|---|
| D3 | 2 | current |
| D4 | 4 | current |
| D5 | 8 | current |
| D6 | 16 | current |
| D7 | 0 | selector-семантика не допущена |
| D8 | 64 | лише research-кандидати |

## Що з цього не випливає

Цей witness не ратифікує жодного D8-резидента, не робить 64 кандидатів
callable і не стверджує нічого позитивного про решту 192 координати D8.

Місткість W8 залишається механічною. Історія Function8/Sens8 не є
семантичною владою.
