# Д10 — дослідження переходу класу без ратифікації

**Дата перенесення:** 11.10.2026. **Статус:** ДОСЛІД, НЕ РАТИФІКОВАНО. Жодної координати D10, команди SENS або фізичного `.sens` файла цей запис не створює.

## Доведене спостереження зовнішнього донора

Історичний Common Lisp / CLOS дозволяє операцією `CHANGE-CLASS` змінити клас існуючого екземпляра зі збереженням його тотожності. Спільний слот зі значенням продовжує містити це значення; спільний слот без прив'язки не стає прив'язаним автоматично. Спостереження не доводить наявності такої реалізації в SENS.

Першоджерело: [ANSI Common Lisp HyperSpec — CHANGE-CLASS](https://www.lispworks.com/documentation/HyperSpec/Body/f_chg_cl.htm). Внутрішні донори: `knowledge/d10-historical-clos-interlisp-residual-review-v1.json` (CLOS-03), попередній дослід [#4842](https://github.com/juv4uk/sens/issues/4842), незалежна пропозиція [#5534](https://github.com/juv4uk/sens/pull/5534).

1. тотожність об'єкта до і після переходу;
2. тотожність об'єкта нового класу;
3. збереження значення спільного слота;
4. відсутність автоматичного зв'язування раніше порожнього слота.

Виконувати: `sbcl --script tests/fixtures/d10-change-class-real-cl-oracle.lisp`. Саме копіювання файла **не означає** нового запуску оракула на поточному HEAD.

## Межа відбору D10

`CHANGE-CLASS` відмінний від створення класу чи об'єкта й читання слота. Але це ще не доводить його незалежності від композиції інших уже відібраних законів. До внесення у `knowledge/d10-v1-semantic-inventory.json` потрібні поведінковий дедуп, незалежні позитивні/негативні свідки, узгоджена append-only історія та актуальні перевірки.
