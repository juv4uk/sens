# D10 · Перевірка повного циклу двійкових вікон де Брейна

Стан 2026-10-09: **RESEARCH / NOT SELECTED / NOT RATIFIED**, `coordinate=null`. Цей документ не дозволяє новий двійковий опкод, синтаксичний маркер D2, операцію таймера чи формат фізичного `.sens`.

## Джерело і точний закон

[SageMath: De Bruijn sequences, `is_debruijn_sequence`](https://doc.sagemath.org/html/en/reference/combinat/sage/combinat/debruijn_sequence.html) визначає циклічне слово порядку `n`, в якому кожне слово довжини `n` зустрічається рівно один раз. Незалежна довідка: [De Bruijn Sequences and Universal Cycles](https://debruijnsequence.org/db/home).

**Дослідна функція:** `DE-BRUIJN-BINARY-CYCLE?` — `повний-двійковий-цикл?` / `чи-усі-н-бітові-вікна-рівно-раз?`.

Входи: скінченна послідовність справжніх D1-бітів `w`, точний додатний цілий порядок `n`. Вихід: тільки D1 `1=YES`, `0=NO`. Результат `1` тоді й лише тоді, коли `len(w)=2^n` і всі `2^n` циклічних вікон довжини `n` різні. Під час побудови вікон **обов'язково переходити через кінець**. Для коректно типізованого, але неповного слова відповідь `0`; не-бітові входи та `n≤0` — доменна помилка.

| Слово | n | Результат | Пояснення |
|---|---:|---:|---|
| `01` | 1 | 1 | `0` та `1` зустрічаються по разу |
| `0011` | 2 | 1 | `00`, `01`, `11`, `10` |
| `00010111` | 3 | 1 | класичний 8-бітовий приклад Sage |
| `00101110` | 3 | 1 | циклічний зсув попереднього |
| `00010110` | 3 | 0 | не всі восьмивіконні коди різні |
| `0101` | 2 | 0 | повтор `01` не є повним словником пар |
| `000101110` | 3 | 0 | на один зайвий біт |

Не плутати з `GRAY-ENCODE-WORD` / `GRAY-DECODE-WORD`, вже відібраними у D10, із `PRIMITIVE-BINARY-WORD-ROOT`, із D8 `ROTATE`, або з дослідженнями `LYNDON` і канонічної циклічної форми. Тут перевіряється **повнота покриття всіх можливих вікон**, а не генератор, обертання, графовий цикл чи спосіб передачі.

## Чому цей закон знадобиться нашим інтересам

- **SENS, двійкова Lisp-машина й WSM-OS-LISP:** вичерпний малий словник D1-вікон для тестів читачів, енкодерів, компілятора, і FPGA-стендів; *це не доводить правильність T5*.
- **Радіотехніка, RTL-SDR, радіоканал SENS і FPGA:** циклічні діагностичні шаблони, які тестують усі `n`-бітні стани; фізичні LFSR-ланцюги, PLL, драйвери, помилки каналу й таймінги залишаються субстратом.
- **Акустика, музика й теорія ритму:** контроль повноти локальних бітових рисунків у циклах; музичні параметри — окремі бібліотеки.
- **Астрономія і фізичні вимірювання:** абстрактні цикли тестових станів вимірювача, а не готова модель ефемерид чи реального часу.
- **Санскрит, Паніні, panca-vac і символічні правила:** математичне покриття усіх бінарних вагових `n`-позиційних фрагментів; не дублювати `RESOLVE-PRATYAHARA` чи звукові поверхні.
- **Аналогові обчислення Spanda, WSM-24, PRAVDA, my-idea:** тестова дискретна послідовність для експериментів із представленнями та інваріантами; жодних припущень про готову реалізацію.
