# Закон цитованих даних: спочатку драбина, потім D7

**Рішення власника: 2026-10-13.** SENS використовує точну доменну ідентичність об'єкта; людські назви — тільки проєкції.

## Нормативний порядок міграції `QUOTE`

1. У контексті цитати перевірити, чи існує **однозначна** ратифікована тотожність об'єкта в драбині.
2. Для `D1`, `D3–D6`, `D8–D10` відтворити **ту саму точну бітність і координату**. Джерело проєкцій — `lib/domains/d*.lisp` та їхні авторитетні реєстри; жодних вручну згенерованих альтернативних кодів.
3. `D2` — тільки структура; `D7` — тільки текстовий носій. Вони не можуть самостійно оголошувати функції.
4. Якщо символ **не має** тотожності у драбині, допустиме лише версійоване, оборотне D7-представлення в структурі D2 з явною роллю цитованого символу. Це не дозволяє автоматично оголошувати D7-дані викличними функціями.
5. Якщо людська назва відповідає різним доменним координатам — **BLOCK**, а не довільний вибір або перехід у D7. Приклад: `MAP` трапляється і в D6, і в D8. Потрібна явно кваліфікована точна тотожність.
6. Числа в D24+ мають власну доменну семантику. Не перетворювати їх у текст D7 при відсутності підтвердженого механізму числових літералів.

## Приклади

| Цитований datum | Канонічна ідентичність | Шлях |
| --- | --- | --- |
| `CAR`, `перше` | `D3:100` | Драбина |
| `QUOTE`, `як-є` | `D3:001` | Драбина |
| `ні`, `NIL` | `D1:0` | Драбина |
| `SQRT`, `корінь` | `D8:00001110` | Драбина |
| `guard-evidence-status?` | `D9:000000000` | Драбина, без автоматичного права виклику |
| `missing-capability` | `D10:0000000000` | Драбина, без автоматичного права виклику |
| `a` | немає відповідності | D7 keyboard/v2, якщо без втрат |
| `MAP` | неоднозначна відповідність | BLOCK |

`QUOTE` не обчислює піддерево; він лише переводить його в дані. Не плутати з `EVAL`/`APPLY`: виконуваність D9/D10 не випливає з їхньої наявності в ратифікованій таблиці.

## Межа доказу

`scripts/migrate-three-pass.py` реалізує вибір координат у **проєкції джерела**. `tests/test_three_pass_quoted_datum_law.py` перевіряє пріоритет, точну ширину, негативний випадок `MAP` та D7 fallback.

Універсальний runtime round-trip `QUOTE` ↔ reader ↔ `Value::DomainIdentity`/`Value::Symbol`, повна семантична парність оракула й типова рамка D7-значення **ще не доведені цією зміною**. Зокрема, звичайний D2-список із W7-елементами не можна автоматично вважати символьним datum. Рядкові літерали мають окрему процедуру допуску; їх не слід мовчки трактувати як функціональні коди.

Контрольний тест: `python3 -m unittest discover -s tests -p 'test_three_pass_quoted_datum_law.py'`. Перевірку CI й незалежного Rust-оракула необхідно проводити окремо.
