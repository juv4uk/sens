# Атомарний випуск трьох проєкцій SENS із допущеного українського джерела

**Завдання:** #4430 / #4449. **Статус:** bounded mechanical implementation, НЕ ратифікація виконуваної семантики чи автоматичне допущення історичних Lisp-програм.

Канонічні три файли одного stem:

| Проєкція | Вміст |
| --- | --- |
| `path/назва.lisp` | незмінене українське джерело `укр`; пробіли й коментарі не змінюють програму |
| `path/назва.sens` | канонічні фізичні байти **T5M**, точні слова й їхні ширини; legacy T5 цей експортер не створює |
| `path/назва` | лише `0/1` слова через один пробіл, рівно один фінальний LF; generated view, а не machine file |

**Незалежний валідатор:** `scripts/verify_uk_t5_t5m_triplet.py` авторитетний для вузького підтриманого корпусу: D1 predicates, D3 QUOTE/ATOM/CDR/CAR/EQ/COND/CONS, D4 CAAR над доведеною CONS-парою та структура D2. Не перекодовувати старі `00001001`, D24/Number, Text7/host-effect, не вигадувати відображення. Якщо з джерела неможливо відновити єдину підтверджену українську програму, операція блокується. Сумісні коментарі й форматування не блокують: порівнюється програма, а не байти `.lisp`.

## Команда

```sh
python3 scripts/publish_verified_uk_triplets.py \
  tests/fixtures/migration-d1-cond-cohort/branch.lisp \
  tests/fixtures/migration-d4-selector-cohort/caar.lisp \
  --mirror /tmp/new-uk-t5-triples \
  --report /tmp/new-uk-t5-report.json --write
```

**Походження фізичних байтів:** без `--write` Python лише обчислює контрольний T5M-еталон (`physical_authority: reference-only-nonpublic`); файл `.sens` не створюється. За `--write` скрипт один раз збирає транспорт закріпленим Zig 0.16, перевіряє SHA виконуваного файла, викликає Zig T5M carry та Zig roundtrip для кожної програми. Публікація дозволена лише коли байти Zig точно збігаються з незалежним Python-еталоном і точними словами; звіт позначає `physical_authority: zig-attested-t5m` та `zig_binary_sha256`. Нестача Zig чи відхилення хоч одного слова — відмова до будь-якого запису. Це доказ транспорту, **не** семантичного виконання SENS.

Без `--write` — лише контрольований preview із SHA джерела, SHA **контрольних**, ще не виданих T5M-байтів, SHA виду, SHA typed-width words. **Відповідник пишеться в окреме дзеркало поза Git-деревом**, щоб не видаляти чужу роботу; `.lisp` лишається непорушним. Скрипт відмовляється перезаписувати будь-який із трьох файлів, відхиляє підозрілі/символічні шляхи, симлінки, зміни джерел у ході запису. Вибраний cohort є транзакцією: один BLOCK — нуль нових файлів; помилка під час публікації відкатує лише створені цим викликом файли.

Після створення викликається **існуючий незалежний** `verify_uk_t5_t5m_triplet.verify()`. Тільки він перевіряє тотожність української програми, **T5M** та ASCII-виду для обмеженої підмножини. Перевірка явно використовує `codec="t5m"` і не приймає legacy-файл за новий. Семантичний оракул **окремо**; у JSON навмисно стоїть `original_executables_oracle_certified: 0`. Це не надає допуску іншим неперевіреним програмам і не дозволяє автоматично виконувати отримані байти.

**CI:** `.github/workflows/verify-uk-t5-triplet.yml` встановлює закріплений Zig, тестує дві вже наявні трійки, перевіряє T5M для новоствореного дзеркала, а історичні T5-фікстури — окремо і генерований view, негативні шляхи/overwrite, повний cohort rollback. Агент може брати лише власний **disjoint canonical UK** cohort, CLAIM у #4449, додати незалежний oracle witness і лише після цього відкривати PR із новими `.sens`.

**Важливо для звітності:** генерація двох уже існуючих fixture в ізольованому CI — тест, **не** дві нові історичні програми в `main`.
