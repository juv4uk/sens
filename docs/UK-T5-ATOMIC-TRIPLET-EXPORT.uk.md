# Атомарний випуск трьох проєкцій SENS із допущеного українського джерела

**Завдання:** #4430 / #4449. **Статус:** bounded mechanical implementation, НЕ ратифікація виконуваної семантики чи автоматичне допущення історичних Lisp-програм.

Канонічні три файли одного stem:

| Проєкція | Вміст |
| --- | --- |
| `path/назва.lisp` | незмінена канонічна українська поверхня `ук` |
| `path/назва.sens` | бінарні байти T5: 5 тритів/байт, `2` **лише** між точними D1–D9 словами, 0–4 pad-`2`, **жодного завершального `22`** |
| `path/назва` | лише `0/1` слова через один пробіл, рівно один фінальний LF; generated view, а не machine file |

**Незалежний валідатор:** `scripts/verify_uk_t5_triplet.py` авторитетний для вузького підтриманого корпусу: D1 predicates, D3 QUOTE/ATOM/CDR/CAR/EQ/COND/CONS, D4 CAAR над доведеною CONS-парою та структура D2. Не перекодовувати старі `00001001`, D24/Number, Text7/host-effect, не вигадувати відображення. Якщо первинний .lisp не **точно canonical ук**, операція блокується.

## Команда

```sh
python3 scripts/publish_verified_uk_triplets.py \
  tests/fixtures/migration-d1-cond-cohort/branch.lisp \
  tests/fixtures/migration-d4-selector-cohort/caar.lisp \
  --mirror /tmp/new-uk-t5-triples \
  --report /tmp/new-uk-t5-report.json --write
```

Без `--write` — лише контрольований preview із SHA джерела, SHA packed bytes, SHA виду, SHA typed-width words. **Відповідник пишеться в окреме дзеркало поза Git-деревом**, щоб не видаляти чужу роботу; `.lisp` лишається непорушним. Скрипт відмовляється перезаписувати будь-який із трьох файлів, відхиляє підозрілі/символічні шляхи, симлінки, зміни джерел у ході запису. Вибраний cohort є транзакцією: один BLOCK — нуль нових файлів; помилка під час публікації відкатує лише створені цим викликом файли.

Після створення викликається **існуючий незалежний** `verify_uk_t5_triplet.verify()`. Тільки він засвідчує взаємну рівність українського джерела, T5 та ASCII-виду для допущеної підмножини. Семантичний оракул **окремо**; у JSON навмисно стоїть `original_executables_oracle_certified: 0`. Це не створює нових історичних міграцій із 490 заблокованих і не дозволяє автоматично виконувати отримані байти.

**CI:** `.github/workflows/verify-uk-t5-triplet.yml`, тестує дві вже наявні трійки, звіряє їхній справжній T5 байт-у-байт і генерований view, негативні шляхи/overwrite, повний cohort rollback. Агент може брати лише власний **disjoint canonical UK** cohort, CLAIM у #4449, додати незалежний oracle witness і лише після цього відкривати PR із новими `.sens`.

**Важливо для звітності:** генерація двох уже існуючих fixture в ізольованому CI — тест, **не** дві нові історичні програми в `main`.
