## Що таке SENS

SENS (СЕНС) — експериментальна двійкова мова, у якій семантична ідентичність =
**точне двійкове слово + точний домен + допущений/доведений закон**. Рівні
упаковані біти в різних доменах не рівні. Rust — референсна реалізація
механізмів, не джерело мовної влади; людські поверхні (`ук/укр/san/en/LISP/sym`)
— проєкції.

## Що в цьому зрізі

- **Contract 11.9.** Ратифіковано D1–D9; **D10** — цілісно 1024/1024
  (акт 12.10.2026); окреме числове сімейство **D24/D48/D96/…**. Ратифікація
  резидента ≠ доведена виконуваність: F1/F2/F3/T5 і callable-механізм лишаються
  окремо gated.
- **Єдиний універсальний адаптивний кодек** (директива #5439): канон — точні
  доменні слова, а не конкретний носій. T5 (`.sens`), F3C (`.senc`) і F3M
  (`.f3m`) відновлюють ту саму семантику.
- **Зміцнений релізний конвеєр:** draft-first і атомарна публікація лише після
  зелених усіх джоб; точний-SHA owner GO (`SENS_RELEASE_GO_SHA`/`_TAG`);
  незалежна перевірка CI на тому самому SHA; SHA-256 provenance + replay
  завантажених байтів; закріплено **Rust 1.99.0** і GitHub Actions на нерухомих
  коміт-SHA.
- **Міграція `.lisp → .sens`** триває: кожна допущена виконувана програма має
  узгоджені `name.lisp` / `name.sens` / extensionless 0/1-view.

**Межа арифметики (уточнення 12.10.2026):** D1–D10 — доменні двійкові слова, не математичні операнди; числові `+ - * / < > =` допускають лише явно кваліфіковані D24/D48/D96/… значення та їхні законні композиції. Код оператора може належати D5/D6, не стаючи числом. Старий Core4 LENGTH використовує бездоменні `0`/`1`, тому міграція цього джерела ще блокує повне приймання; зміна збережена у `RELEASE-EVIDENCE.md` як **BLOCKED**, а не PASS. Обидва основні Core CI тепер викликають `math_domain_exclusivity` і FASL-negative controls, але green-результат на candidate SHA поки не підтверджено.

## Встановлення

- Бінарники: `linux_amd64`, `windows_x64` (`.exe` і `.msi`), `macos_x64`,
  `macos_arm64`.
- `install.sh` — з релізу; **портативний веб-REPL** — один самодостатній `.html`,
  без встановлення.
- `islands-manifest-v1.json` містить SHA-256 кожного активу;
  `release-provenance.json` фіксує тег, commit і контракт.

## Чого цей реліз НЕ обіцяє

- Повного компілятора, самодостатнього bootstrap, універсального binary-source
  cutover чи автоматичного виконання кожного ратифікованого резидента.
- Підтвердженої незалежної parity на кожному GPU/FPGA/GraalVM/CML/радіоканалі.
- Гарантованого прискорення чи економії без вимірювань (workload, host, точний
  SHA, raw evidence).
