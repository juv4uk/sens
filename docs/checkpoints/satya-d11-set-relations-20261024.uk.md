# Satya — D11 множини, 24.10.2026

## Першопричина
Ланцюгові закони перевіряли форму списків, але безпосередні належить-за-порівнянням?, підмножина-за-порівнянням?, правий-елемент-є-зліва?, праві-елементи-є-зліва? та множини-рівні-за-порівнянням? мали ранні результати D1 без повної перевірки решти входів. Порожня ліва множина могла приховувати зіпсовану праву; перший збіг міг приховувати неправильний хвіст.

## Виконане в SENS
Публічні виклики спочатку виконують правильна-множина? для кожного аргументу; неправильний хвіст спрямовується до (перше ні), де нативний D3 мусить видати Type. Після перевірки працюють окремі рекурсивні ядра, не дублюючи валідацію на кожному кроці. Ланцюгові функції вже перевіряють усі вкладені множини й викликають ядра напряму. Порядок компаратора (лівий, правий) збережено. Ратифіковані коди не змінювалися.
