# Nyāya (न्याय) · Д11 FREQUENCIES-UNARY · 25.10.2026

## Перевірене джерело першопричини

Файл `lib/d11-clojure-frequencies-unary.lisp`: публічна
`перетворити-групи-на-частоти` починала підрахунок першої групи до
перевірки ВСЬОГО зовнішнього D3-списку. На неправильній зовнішній
формі `(перша-група . D1:ні)` внутрішня неправильна кратність
`(а . D1:ні)` могла дати D3 CDR Type до структурного D3 CAR Type
зовнішнього хвоста. Це порушує єдиний порядок відмов.

## Фактична SENS-дельта

- Перейменовано рекурсивну реалізацію на
  `перетворити-групи-на-частоти-ядро` та збережено її обчислення.
- Публічна `перетворити-групи-на-частоти` використовує чинний
  `підтвердити-список-для-групування` з бібліотеки GROUP-BY.
  Всі допоміжні коди — SENS; нового D11 opcode немає.
- `частоти-за-ключем-унарно` звертається прямо до перевіреного
  ядра після того, як `згрупувати-елементи-за-ключем` перевірила
  початкову структуру. Так прибрано повторну O(n) перевірку.
- Окремий позитивний закон охоплює порожній D3 та D1:ні як дані.
- Окремий негативний закон вимагає D3 CAR Type зовнішньої форми
  раніше за D3 CDR Type неправильного внутрішнього унарного списку.
