# Satya (सत्य) · D11 GROUP-BY · 25.10.2026

## Знайдена першопричина
`lib/d11-clojure-group-by.lisp`: три прямі входи `вибрати-елементи-з-ключем`, `вилучити-елементи-з-ключем`, `розділити-елементи-за-ключем` обходили список і могли викликати користувацький ключ до перевірки повного D3-суфікса. При `(сполучити так ні)` помилка callback `CDR Type` могла випередити `CAR Type` структурної D3-помилки.

## Точне SENS-виправлення
Три чинні рекурсивні тіла збережені, переназвані на `*-ядро`, включно з внутрішніми рекурсіями. Публічні обгортки перевіряють список через вже наявний `підтвердити-список-для-групування` один раз. Зовнішнє групування викликає внутрішнє `розділити-елементи-за-ключем-ядро`, бо вже викликало свій D3 preflight. Збережено точні імена, порядок елементів, функцію ключа, модель D1:ні ≠ D3:() і всі старі очікувані результати. Без нових машинних кодів, хостової семантики чи D7 дублювання.
