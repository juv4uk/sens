# D10: найкоротше слово розрізнення скінченних автоматів (дослід)

**Статус:** `PROPOSE / pending-review`; **НЕ** ратифікований D10 resident. Координата `null`. Авторитет D1–D9 і D2 не змінюється. Головні задачі: #4013, #4463; один глобальний домен #4162.

## Кандидат

- Назва досліду: `FINITE-MEALY-DISTINGUISHING-WORD`.
- `ук`: `розрізнити-автомати`; `укр`: `найкоротше-розрізнювальне-слово`.
- Аргументи: два повні детерміновані скінченні автомати Мілі над тією самою скінченною впорядкованою абеткою, кожен із початковим станом. Тестовий оракул обмежений початковим станом 0, вихідними бітами 0/1, розміром абетки 1–4; ці обмеження — **не** пропозиція загального закону SENS.
- Результат: або порожня відсутність свідка `None` у Python-оракулі (кожне скінченне слово породжує однаковий вихідний потік), або **найкоротше, а серед таких лексикографічно перше вхідне слово**, після якого вихідні потоки різні. Python `None` не означає і не впроваджує D3 `()` чи D1:0.
- Спостережуване відношення: `observed(A,w) = observed(B,w)` для всіх слів `w` тоді й лише тоді, коли свідка немає.
- Ніяких host-ефектів, адрес, драйверів, I/O чи нової граматики D2.

## Доказова межа

Перебираємо досяжні пари станів `(qA,qB)` від початкової пари у ширину, а символи — в канонічному порядку. На першій розбіжності виходів повертаємо шлях. BFS гарантує мінімальну довжину, а порядок алфавіту + FIFO — лексикографічно найменший свідок серед найкоротших.

Якщо відвідано всі досяжні пари без розбіжності, автоматів не відрізнити скінченним словом: для кожного наступного символу виходи однакові і наступна пара вже належить замкненій множині. Довжина найкоротшого свідка, якщо він існує, не перевищує `|QA| × |QB|`: перед першим розходженням не може повторитися пара без можливості видалити цикл та отримати коротший свідок.

**Це доведення конкретного алгоритму, а не доказ, що операція мусить стати примітивом SENS.** Окремо потрібно відрізнити самостійний універсальний закон від бібліотечної композиції обходу графа, перевірки виходу й узагальненого пошуку.

## Відтворювана перевірка

```sh
python3 research/d10/mealy_distinguishing_word.py
python3 -O research/d10/mealy_distinguishing_word.py
```

- Два різні алгоритми: BFS по парах станів і повний лексикографічний перебір слів із прямою симуляцією потоків до `|QA|×|QB|`.
- **256** усіх двостанних повних автоматів над двосимвольною абеткою з бітовими виходами; **65 536** впорядкованих пар. Для кожної порівнюються повні результати двох алгоритмів.
- Позитивний свідок: розрізнення лише після входу `(0,0)`. Негативні: недосяжна відмінність; однаковий автомат; неповна таблиця, недійсний стан і небітовий вихід.
- Обидва незалежні за алгоритмом оракули написані Python: це **не** незалежний SWI/FPGA/Rust proof; існує ризик спільної помилки моделі, тому зовнішній оракул лишається відкритою перевіркою.
- Локальний контроль (11.10.2026): усі 3 групи `unittest` PASS зі звичайним Python та `python -O`; це не Hosted CI.
