# D13 — сміливий ескіз (НЕ ратифіковано)

D11 = 11 біт, похідні селектори від D10 + сімейні закони.
D12 = дослідне щільне пакування (Dense-D12 у experiments) — транспорт, не семантика.
**D13** = місце для законів **композиції композицій**, якщо D11 уже тісний.

## Правило сміливості
1. Спершу `search-domain-function.py` і D1–D10.
2. Потім D11 (selector-suffix або сімейний закон).
3. D13 лише коли потрібна **нова математична вісь**, не ще один alias map.

## Кандидати-ескізи (без opcode)
| Ім'я | Ідея | Чому не D6/D11 |
|------|------|----------------|
| `поряд-застосувати` | juxt: кілька ф → один x → список | Не `відобразити`, не `скласти-функції` |
| `дзеркало-дерева` | структурний reverse на дереві | Не `перевернути` списку |
| `закон-футамура-1` | спеціалізація інтерпретатора як дані | Дослідження, не примітив |

## Заборона
- Не заводити D13-таблицю з випадковими словами.
- Не давати координат без закону + свідка + рішення власника.
- Не дублювати `згорнути`/`відобразити`/`усі?`.

Статус: **ескіз конкурсу**, не робочий домен.
