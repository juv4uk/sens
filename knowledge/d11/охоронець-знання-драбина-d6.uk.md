# Охоронець: знання драбини (не дублювати в D11)

Перед пропозицією в D11 — перевірити наявність у D1–D10:

| Запит агента | Уже є | Домен |
|--------------|--------|-------|
| map / foreach unary | `відобразити` | D6 |
| filter | `відсіяти` | D6 |
| fold / reduce | `згорнути`, `накопичувати` | D6 |
| every / all | `усі?` | D6 |
| any / some | `будь-яке?` | D6 |
| apply | `застосувати` | D4 |
| compose | `скласти-функції` | D6 |
| partial | `частково-застосувати` | D6 |
| append | `приєднати` | D4 |
| length | `довжина` | D6 |
| car/cdr/cons/eq/cond/quote/atom | `перше` `решта` `сполучити` `тотожне?` `за-умовою` `як-є` `атом?` | D3 |
| define/lambda | `визначити` `функція` | D4 |

D11 лише для **щілин**: напр. `поряд-застосувати` (juxt), якщо не зводиться до `відобразити`+`список`.

Команда: `python3 scripts/search-domain-function.py <назва>`
