# Охоронець: знання драбини (не дублювати в D11)

Перед пропозицією в D11 — перевірити наявність у D1–D10:

| Запит агента | Уже є | Домен |
|--------------|--------|-------|
| map / foreach unary | `відобразити` | D6 |
| filter | `відсіяти` | D6 |
| fold / reduce | `згорнути`, `накопичувати` | D6 |
| every / all | `усі?` | D6 |
| any / some | `будь-яке?` | D6 |
| apply | `застосувати` | D4 |
| compose | `скласти-функції` | D6 |
| partial | `частково-застосувати` | D6 |
| append | `приєднати` | D4 |
| length | `довжина` | D6 |
| car/cdr/cons/eq/cond/quote/atom | `перше` `решта` `сполучити` `тотожне?` `за-умовою` `як-є` `атом?` | D3 |
| define/lambda | `визначити` `функція` | D4 |

D11 лише для **щілин**: напр. `поряд-застосувати` (juxt), якщо не зводиться до `відобразити`+`список`.

Команда: `python3 scripts/search-domain-function.py <назва>`

## Експериментальна гра й кодек D11

- Канонічне джерело запитань — `lib/domains/d1.lisp` … `lib/domains/d11.lisp`; Zig не дублює семантичну таблицю.
- У D11 зараз 512 математично похідних селекторів: для ратифікованого батька (p) з D10 маємо (p_0(x)=p(перше(x))) і (p_1(x)=p(решта(x))). Це композиції, не нові примітиви чи дозвіл на прямий D11 opcode.
- `research/zig-codecs/ladder_memory_game.zig` формує відтворюваний порядок запитань за seed, перевіряє повне покриття 512 координат та рахує правильні відповіді, помилки, повтори, невідомі координати й пропуски. D7 — дані, а порожній LISP-резидент — структура, не пригадана функція.
- `research/zig-codecs/d11_selector_contest.zig` кодує лише явно оголошений потік цих 512 суміжних координат: локальний 9-бітний індекс не можна застосувати до довільного змішаного потоку D11 без зовнішнього кадру.
- Бенчмарк порівнює 9-бітний індекс, загальне 11-бітне слово і 16-бітний big-endian еталон на тих самих 64 та 512 координатах. До вимірювання обов'язковий точний roundtrip; 15 зразків ідуть у чергованому порядку; звіт містить p50/p90 часу повного encode+decode, фізичні байти та співвідношення з u16. Це вимірювання транспорту, не оцінка семантики SENS.
- Не оголошувати переможця за одним заміром чи лише за розміром одного файлу. Спершу однакові слова й доведений roundtrip, потім p50/p90 та межі застосовності. Не прирівнювати механічне покриття гри до ратифікації D11.
