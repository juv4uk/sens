## Прохід по драбині

Перечитано чинні `lib/domains/d1.lisp` — `d10.lisp`. Перевірено бітність і відсутність повторних координат для кожного домену: **2 + 4 + 8 + 16 + 32 + 64 + 128 + 256 + 512 + 1024 = 2046/2046 рядків**. Це **статична повнота таблиць**, не підтвердження виконання кожного резидента.

Сім викличних голів з `lib/tcp.lisp` мають точні ратифіковані повні назви в колонці `укр` дев'ятого домену:
`протокол-передавання-слухати-на`, `протокол-передавання-слухати`, `протокол-передавання-читати-байти-текст`, `протокол-передавання-читати`, `протокол-передавання-записати-текст-байти`, `протокол-передавання-записати-через-сирий`, `протокол-передавання-записати`.

Три залишкові TCP raw-виклики були **механізмами хоста**, а не невідомими функціями мови. Збережено старі імена на межі сумісності в Rust, додано українські імена тим самим handler'ам. Жодного переведення історичного SID8/Sens8 на Д8 і жодних закодованих голів не виконано.

## Важливі межі

- **Повний український файл** — тільки коли всі його символи, разом із коментарями та даними, можна набрати українською клавіатурою. Попередній звіт рахував міграцію окремих `let` у машинному `x86-64.lisp` за один файл, але за цим суворим критерієм такий файл **не є повністю українським**. Він не входить у поточну одиницю.
- `IMPLEMENTED / NATIVE_UNVERIFIED`: зареєстровано механізми та додано нативний тест, але Cargo/SENS/важкі ранери вручну **не запускалися**. Не оголошувати PASS без реального виконання.
- Не створено нових workflow, глобальних HOLD, власницьких ратифікацій чи окремих гілок. GitHub Contents API робить коміт і push у головну гілку при кожному записі.

## Подальший обсяг

Інші активні `.lisp`, у яких залишилися протокольні дані, зовнішні назви, коментарі або машинна механіка не з української розкладки, **не** зараховано до повністю перенесених. Потрібна окрема міграція з доказом збереження зовнішніх протоколів. Д11 розглядати лише після пошуку незалежного закону, а не за відсутністю текстового написання.
