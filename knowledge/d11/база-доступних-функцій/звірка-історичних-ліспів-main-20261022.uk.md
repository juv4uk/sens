**Дата:** 22.10.2026. **Статус:** дослідне походження, не виконавчий дозвіл і не ратифікація.

## LOOPS 1983: два справжні історичні дослідження, тепер явно в каталозі

Джерело: [архівний оригінальний витяг LOOPS](../../../research/domain-archive/20261011/pr4883/knowledge/d10-loops-active-values-intake-v1.json), SHA Git blob `f88711aa939c84f55e61038cf4d362731d8f4597`, *The LOOPS Manual* (D. G. Bobrow, M. Stefik, 1983), §§5.1, 5.2, 5.5. Незалежне [навчальне джерело Xerox PARC 1983](https://xeroxparcarchive.computerhistory.org/indigo/loops/.LoopsCourseSummary.bravo%211.html) підтверджує будову активного значення `#(localState getFn putFn)` та відмінність читання від запису.

| Історична назва / українська проєкція | Закон, який треба виконати в SENS | Критичний контрприклад |
|---|---|---|
| **ACTIVE-VALUE-GET** / `читати-активне-значення` | Обхід вкладених getFn **внутрішній → зовнішній**; відсутній getFn не знищує локальний стан. Архівний приклад: `(10 + 2) × 3 = 36`. | Зовнішній getFn перед внутрішнім або обхід `GetLocalStateOnly`, який помилково запускає обробники |
| **ACTIVE-VALUE-PUT** / `записати-активне-значення!` | Зовнішній putFn діє **перед** внутрішнім, але внутрішній отримує керування лише після явного делегування; без putFn змінюється власний localState. | Самочинний запис у внутрішній об'єкт без делегування або запуск обробника під час `PutLocalStateOnly` |

**Нинішній статус:** `HISTORICAL_BEHAVIORAL_LAW_RESEARCH_NATIVE_SENS_UNVERIFIED`. Обидві назви віднині внесено як **архівні дослідні рядки** в `кандидати.json`: `coordinate=null`, `callable=false`, `ratified=false`, виконавчих файлів `.lisp` для них не засвідчено. Це не нові machine opcodes.

**Доказ незалежності ще відкритий:** D10 уже має `DEREF` `0100000000`, `REF-CELL` `0100000111`, `SLOT-VALUE` `0000001111`, `RESET-REF!` `0100001011`, `SWAP-REF!` `0011111001`. Перед підвищенням статусу потрібно показати, що композиції із SENS closures і D10 не дають тотожного зовнішньо видимого результату. Якщо дають — це бібліотечний похідний закон, не примітив.

## Що навмисно не стало новими переможцями

- **LISP I / Lisp 1.5 (McCarthy):** `APPQ`, `DEFINE-BATCH` уже живуть у [`d10-crossrepo-early-lisp-v1.json`](../../d10-crossrepo-early-lisp-v1.json) з власними історичними поясненнями; спершу звіряти їх із D4/D5, а не копіювати до D11.
- **MACLISP:** історичні `NCONC`, `NREVERSE` у дослідному каталозі потребують саме **руйнівної семантики і тотожності осередків**; звичайний не руйнівний `APPEND`/`REVERSE` не доводить їхній закон. Джерело: [`d10-historical-maclisp-v2.json`](../../d10-historical-maclisp-v2.json).
- **Interlisp / PSL / Lisp Machines:** [`d10-psl-interlisp-lispm-unmerged-residual-v1.json`](../../d10-psl-interlisp-lispm-unmerged-residual-v1.json) має 21 предметний дослідний запис, але жодного нового допущеного коду.
- **CLOS MOP:** 15 історичних назв уже входять до `кандидати.json`; метаоб'єктні читачі і життєвий цикл не дублювати з D10 `SLOT-VALUE` за схожим ім'ям; див. [`d10-mop-metaobject-reader-census-20261009.json`](../../d10-mop-metaobject-reader-census-20261009.json).
- **Common Lisp HyperSpec / R7RS / MAL:** streams/conditions, bytevector і друк/читання відокремлювати від доменів D7, D24+ і зовнішнього I/O; перенесення чужого host API в D11 заборонене.
- **Не підтверджені джерелом:** `BACKQUANTIZE`, `COLLECTION`, `GENERATE-EXPANSION`, `TABLESPACE` із 82 архівних трійок лишаються без підвищення: записані негативні вимоги, але немає самостійної сучасної SENS-семантики чи первинного підтвердження.

## Наступний випробувальний напрям

Для LOOPS потрібні **два різні нативні набори**, не Python-імітація: позитивний і негативний `getFn` із перевіркою трасування `inner→outer`, та позитивний і негативний `putFn` із перевіркою `outer→inner`/відсутності несанкціонованого делегування. Всі проміжні дані — SENS; Zig тільки кодовий шлюз, Rust тільки запуск та ввід/вивід. Без цього статус не підвищувати.

Для 92 спискових програм спочатку зіставити **реальний структурний закон** із D3 CAR/CDR/CONS, математичними селекторами, D8/D9 списковими законами та історичними руйнівними операціями. Фізична пара `.lisp ↔ .sens` сама по собі не створює 92 нових семантичних одиниць.

**Незмінний результат:** 512 математичних селекторів + 43 підтверджені композиції = **555 визначених функцій D11**; історичний каталог кандидатів розширено на два вже задокументовані дослідження, а не на вигадані примітиви.
