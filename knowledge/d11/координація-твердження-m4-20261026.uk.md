# Координація · M4 CI-ланцюгер · 2026-10-26

## Рішення
Тонкий Rust-тест `crates/sens/tests/твердження_runner.rs`:
- механічний запуск M1/M2/M3 laws
- mutant CAR → очікувана відмова
- без дублювання таблиць істинності

## Симетрія трикутника
| Шар | Роль |
|-----|------|
| SENS | судження, laws, звіти |
| Rust | завантаження, код виходу, відмова |
| Zig/T5M | фізична пара (окремі CI) |

## Запуск
```
cargo test -p sens --test твердження_runner
```

## Обмеження
Без `--serve` кожен тест = новий процес/сесія (спавн).
Тепла сесія — наступний крок ефективності, не семантики.
Локально: Rust 1.75 недостатній для edition2024 workspace — ганяти на CI.
