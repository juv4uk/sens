# Політика шарів тестів

| Шар | Що перевіряє | Мова тесту |
|-----|--------------|------------|
| Носій / рантайм Rust | ABI, dispatch у crates, FS API хоста | **Rust** (`crates/*/tests/*.rs`) |
| Фізичний кодек Zig/T5M | mint, pair, inverse, bit packing | **Zig** (`research/zig-codecs`, T5M) |
| Мова, семантика, логіка | домени D1–D10, закони, предикати, списки | **Lisp** (укр проєкція, `.lisp` + `.sens`) |

Правила:
1. Тест семантики не імпортує Rust/Zig і не залежить від Python/JSON.
2. Тест механізму не підміняє закон мови «зеленим» хост-ассертом.
3. Свідок мови — виконуваний Lisp: `визначити` / `функція` / `за-умовою` / `тотожне?` / …
4. Коди доменів — першокласні значення; без восьмибітної онтології.
