# Дослідний Rust-кодек T5 / Рамка-3 / Tb-33

**Статус: експеримент. Канонічний `.sens` лишається T5 і не змінюється.**
Це окремий дослідницький носій (`.senc`) з явною міткою, а не ратифікований формат.

Це Rust-переклад дослідного Python-оракула з `research/framed3/`:

- `senc.rs` — самодостатній модуль (`std` без зовнішніх залежностей, власний
  мінімальний big-uint для F3; Tb-33 вміщається в `u128`);
- `parity.rs` — Rust-харнес, що читає TSV-вектори й перевіряє кожен крок через
  публічний API (`encode_smallest`, `read_carrier`, `decode_senc`);
- `gen_vectors.py` / `gen_negatives.py` — генератори векторів із Python-оракула;
- `run_parity.sh` — одна команда для повного диференційного доказу.

Джерело байтів (authority паритету) — уже влитий дослід
`research/framed3/adaptive_encoder.py` + `research_codec.py` + `tb33_tail_research.py`
(гілка `main`, коміт `0f119d2a5`, issue #5429 / #5439).

## Запуск

~~~sh
research/framed3/rust_codec/run_parity.sh
~~~

Очікуваний результат: `=== parity: N/N ok, 0 failures ===`.

Внутрішні тести модуля (вичерп на малих довжинах, негативні мутанти, межі):

~~~sh
rustc --edition 2021 --test research/framed3/rust_codec/senc.rs -o /tmp/senc_test
/tmp/senc_test
~~~

## Результат паритету (2026-10-10)

`1703/1703 ok, 0 failures` — 1672 позитивні (вичерпні малі довжини, рамка,
Tb-33, адаптивний вибір, явна маршрутизація за міткою) + 31 негативний
(невикористані фізичні коди, неканонічний T5, битий F3/F4).

Під час паритету знайдено й виправлено **дві реальні розбіжності** з оракулом:

1. **Порожній T5**: Python-оракул приймає порожній `.sens` як порожній список
   слів; перша версія Rust відкидала його. Узгоджено з оракулом.
2. **Канонічність `0xf2`** (усі транспортні трити — `2`): після зняття хвостових
   `2` потік порожній; Rust мусить усе одно звірити канонічне повторне
   кодування й відкинути байт, а не «тихо» прийняти його.

Обидві розбіжності — це саме той клас помилок, який дає незалежний оракул.

## Межа (чому це НЕ в `crates/sens`)

Страж `scripts/check-t5-default-boundary.py` (донесений #5469 / лейн #5442)
**заморожує** межу: будь-яка згадка `.senc|framed3|framed4|tb33|adaptive_encoder`
у канонічних крейтах `crates/sens` та `crates/sens-cli` заборонена. Тому цей
кодек живе під дозволеним префіксом `research/`, поки лейн #5442 не еволюціонує
межу під етап Б епіку #5438 (спільний API + CLI).

Цільове місце на етапі Б (коли межу відкриють): `crates/sens/src/codec/`, з
під'єднанням локального `t5_encode`/`t5_decode` до канонічного
`ternary_transport` як **другого незалежного оракула** (окремий Rust-свідок).

## Чого це НЕ доводить

- Не доводить глобальну оптимальність кодекa і не є перевагою швидкості без
  парних бенчмарків на одному фізичному хості.
- Не робить `.senc` канонічним і не змінює семантику T5.
- Не замінює рішення власника про введення формату.
