# D10 — канонічне топологічне впорядкування (дослід, 11.10.2026)

**Стан:** новий дослідний кандидат, `selected=false`, `ratified=false`, `coordinate=null`. Жодних змін D1–D9, D2, T5, `.sens`, канонічного інвентарю чи журналу заявок.

## Паспорт семантичного закону

- **Назва для дослідження:** `CANONICAL-TOPOLOGICAL-ORDER`.
- **Українська поверхня:** `упорядкувати-залежності`.
- **Скорочена українська поверхня:** `найменший-топопорядок`.
- **Закон:** дано скінченну множину вершин із точним повним порядком і скінченну множину орієнтованих ребер. Якщо існує топологічне впорядкування, повернути **лексикографічно найменшу** перестановку всіх вершин, для якої кожне ребро `u→v` задовольняє `pos(u)<pos(v)`. Якщо присутній орієнтований цикл (включно з петлею), повернути **CYCLIC**, не вигадувати частковий успіх і не перетворювати граф на неорієнтований.
- **Межа дослідного оракула:** вершини `0…n-1`, точні цілі, `0≤n≤7`. Ця тестова межа НЕ є твердженням, що мовний закон має обмежуватися сімома вершинами. Відсутні вершини, дублі ребер, дробові та логічні індекси заборонені.
- **Власність Core/бібліотека:** HOLD, не доведена нерозкладність на ратифіковані операції. Це не новий opcode і не дозвіл на виділення 10-бітного слоту.

## Джерела станом на 11 жовтня 2026

1. Arthur B. Kahn (1962), *Topological Sorting of Large Networks*, CACM 5(11), 558–562; https://doi.org/10.1145/368996.369025 — історичний базовий метод топологічного впорядкування.
2. Стандартна бібліотека Python 3.14, `graphlib.TopologicalSorter`: https://docs.python.org/3.14/library/graphlib.html — орієнтир щодо циклу та впорядкування, але її порядок залежить від порядку додавання; отже, наш канонічний lex-min закон не тотожний типовому API.
3. Наявний донорський перелік власника `knowledge/d10-interest-proposal-v1.json` у `juv4uk/sens`, родина `graph`, містить `topological-sort`.
4. Суміжна, але інша неретифікована пропозиція `knowledge/d10-canonical-directed-cycle-witness-research-v1.json` повертає **канонічний свідок циклу**. Поточний кандидат натомість повертає канонічний **порядок для DAG** або факт циклічності без свідка.

## Оракули та фальсифікація

Файл: `tools/research_d10_canonical_topological_order.py`.

- Оракул A: алгоритм Кана, мінімальна купа доступних вершин.
- Оракул B: незалежний повний перебір перестановок за лексикографічним порядком; не імпортує реалізацію A.
- Локально звірено **66 835** графів: усі можливі орієнтовані графи з петлями для `n=0…4` (66 067), плюс по 256 детермінованих зразків для `n=5,6,7` (768).
- Додаткові негативні контролі: цикл із трьох вершин, петлі, невірний індекс, дубль ребра, `bool` як індекс, порожній граф.
- Локальні виконання: `python3 tools/research_d10_canonical_topological_order.py` та `python3 -OO tools/research_d10_canonical_topological_order.py`; обидва PASS. Перевірки не покладаються на Python `assert`, що зникає під `-O`.
- Не перевірено незалежним фізичним SENS-оракулом. Цей код — **тимчасовий host research oracle**, не основна реалізація мови.
