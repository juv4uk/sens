# #2000 — benchmark масштабування без верхньої межі ширини

Лише дослідження. Структури carrier не мають мовної максимальної ширини.

Кандидати:
- динамічні heap-байти;
- small-inline до 64 біт включно з динамічним spill вище 64 біт.

4096 — лише тестова точка, а не межа carrier/type.

Перед кожним вимірюванням перевіряються:
- equality з урахуванням точної ширини;
- нуль з однаковим числовим значенням на сусідніх ширинах лишається різною identity;
- append, а потім parent, відновлює початкове слово;
- початкове слово є точним prefix свого appended child.

Smoke:

    python3 benchmarks/unbounded-width/run.py --smoke

Повний sweep по ширинах та операціях:

    python3 benchmarks/unbounded-width/run.py

Перша spilled-реалізація append/parent навмисно проста і може бути O(width).
Цей slope є evidence про механізм, а не семантичною вимогою; наступні chunked-кандидати можуть його покращити.
