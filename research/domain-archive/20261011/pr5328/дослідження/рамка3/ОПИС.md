# Рамка-3 — дослідний фізичний носій SENS

**Статус: ДОСЛІД, не ратифіковано, не замінює канонічний `.sens` (T5).**

## Математична передумова

У розглянутому класі **одна програма — одна зовнішня D2-форма**:
початок `10`, кінець `01`; внутрішні D2-дужки можуть бути вкладені.
Транспортний `2` ставиться **лише між** точними двійковими словами D1–D9.
Отже, транспорт не містить сусідніх `22`; на краях немає транспортного `2`.
Корисний набір тритів для кожної довжини перераховується математично,
а не зберігається у таблиці англійських імен.

Ранжування допустимих рядків за довжиною дозволяє відновлювати трити
з фізичних байтів. Кількість байтів задає групу довжин; діапазон рангу
задає точну довжину в групі. Не використовуємо кінцевий `2` або EOS.
Це *префіксно-суфіксна* комбінаторна модель, не нова семантика D2.

| Розмір | Довжини в тритах | Усього облікових рядків |
| --- | --- | ---: |
| 1 байт | 5–11 | 139 |
| 2 байти | 12–17 | 57 504 |
| 3 байти | 18–22 | 8 716 160 |

**Увага:** підрахунок містить рядки, які не є правильними D2-програмами.
Фізичний декодер перевіряє доменні слова й баланс рамки, але **не замінює
канонічний D2-парсер чи незалежний семантичний оракул**. Зміст програми
визначається на інших шарах. Не змішуйте ці байти з T5 без явного
визначення фізичного формату. Поточний прототип обмежено вісьмома байтами;
потокове кодування довгих програм і розрізнення версій не реалізовані.

## Свідки

- `10 001 00 000 01`: чинний T5 — 4 байти; Рамка-3 — 2 байти.
- `10 100 00 10 111 00 1 00 0 01 01`: T5 — 7 байтів; Рамка-3 — 5 байтів.
- Недопустимі рамки, надлишкові вирази та незайняті фізичні коди відкидаються.

Запуск із кореня репозиторію:

```sh
python3 дослідження/рамка3/перевірка_носія.py -v
```

## Наукові джерела для подальшої перевірки

- *Universal Framework for Parametric Constrained Coding*, IEEE Transactions
  on Information Theory (2026), DOI: 10.1109/TIT.2026.3672710.
- *Combinadic Compression: An Order-0 Enumerative Byte-Stream Codec with
  Size-Preserving Encryption*, Algorithms (2026),
  DOI: 10.3390/a19080634.

Модель з цих праць не запозичено механічно; наведені як сучасні підходи
до скінченно-станового/комбінаторного кодування, які слід порівняти
з точними рамковими законами SENS. Кодер **не має** права міняти D1–D9,
`main` виконавець, Core4 FASL або незаявлено запускати іншу граматику.

## Вичерпне свідчення 0–12 тритів (окрема дослідна гілка)

У таблиці [`свідчення_до12.json`](свідчення_до12.json) наведено **всі**
\(\sum_{n=0}^{12}3^n=797161\) можливих рядків із транспортного алфавіту
`{0,1,2}` для кожної окремої довжини 0–12. Незалежна перевірка відокремлює
**379** рядків із заданими краями `10 2 … 2 01` і без `22`, а серед них
**302** рядки, які відповідають додатковій, обмеженій перевірці слів цього
кодера; **77** рамок не допускаються. Це не кількість програм у повній
канонічній граматиці D2.

Вичерпно перевірено лексикографічний `rank/unrank` для кожної рамки,
`pack/unpack` для кожного допустимого запису, однозначність виданих байтів,
неперевищення довжини довідкового T5 та **всі 256 одно-байтових кодів**
з відхиленням недопустимих. Таблицю прив'язано до **точного Git blob**
`носій.py` і перевіряється засобом `git hash-object`. Результати
не підміняють незалежну канонічну перевірку D2 із задачі #5313.

Відтворення без нового workflow:

```sh
python3 дослідження/рамка3/вичерпність_до12.py
python3 -O дослідження/рамка3/вичерпність_до12.py
```

Повторна генерація таблиці після перевіреної зміни кодера (лише окремим
комітом з рев'ю): `python3 дослідження/рамка3/вичерпність_до12.py --write`.
Довжина понад 12, багатоформність, версія транспортного заголовка,
пошкоджені довгі потоки, CRC та повна D2-семантика тут **не доведені**.

Сучасні орієнтири (без приписування їм доказів SENS): Bose–Tallini,
*On the proper enumeration of all finite length strings for source coding*
(2026), DOI `10.1016/j.kjs.2026.100537`; *Universal Framework for
Parametric Constrained Coding* (IEEE TIT, березень 2026),
DOI `10.1109/TIT.2026.3672710`.
