# D10 — точне раціональне наближення зі світу `spanda`

**Статус:** один `pending-review` кандидат, **NOT-SELECTED**, `coordinate=null`, `ratified=false`. Математичний proof-first intake, без зміни канонічної D10 таблиці або .sens програми. Координація [#4463](https://github.com/juv4uk/sens/issues/4463), [#4301](https://github.com/juv4uk/sens/issues/4301).

## Звідки виникла ідея

Власний `juv4uk/spanda`, `README.md` Git blob `d339363e03798941280d7394fb6b24a76ff43dd3`, рядки 19–38: трикутник «SENS p/q — FPGA матриця ключів — аналогова машина» та повернення аналогового вимірювання до найближчого дробу через неперервні дроби / дерево Штерна–Броко.

Первинний інженерний контекст — **точні раціональні закони**. Жодна фізична напруга, регістр ADC, формат маски або показник датчика не стає через це новим примітивом мови. Мовний закон має працювати з будь-якими точними раціональними числами на CPU, FPGA або без жодного заліза.

Для математичної поведінки є незалежна реалізація та документація: [CPython `Fraction.limit_denominator`](https://docs.python.org/3/library/fractions.html#fractions.Fraction.limit_denominator), [CPython `Lib/fractions.py`](https://github.com/python/cpython/blob/main/Lib/fractions.py). Авторська SENS-версія повинна спиратися на власну семантику точного дробу, не запозичувати Python ABI.

## Один кандидат

**`BEST-BOUNDED-RATIONAL`** — ук `ндрм`, укр `найближчий-дріб-у-межі-знаменника`.

Вхід: точне раціональне `x=a/b` (b>0) та позитивне ціле `M`. Вихід: скорочений дріб `p/q` із позитивним `1≤q≤M`, що мінімізує точну похибку `|a/b - p/q|`. Якщо є кілька мінімумів, вибрати мінімальний знаменник; якщо й той однаковий — **менше числове значення**. Якщо M<1, відмовити. Для float без явного раціонального представлення **не припускати**, що це дійсне точне число вимірювання.

Обов'язкові приклади:

| Вхід `x` | `M` | Вихід | Причина |
|---|---:|---|---|
| `3/2` | 1 | `1/1` | точна нічия між цілими: нижнє |
| `-1/2` | 1 | `-1/1` | від'ємна нічия: нижнє |
| `355/113` | 1000 | `355/113` | точний знаменник уже допустимий |
| `31415926535897932/10^16` | 1000 | `355/113` | десяткове *наближення* π задане точним дробом |
| `2/7` | 3 | `1/3` | строгий обмежений оптимум |

Порівнювати похибки можна **без float**, за перехресним множенням або точною арифметикою `Fraction`. Саме `M` відрізняє закон від ратифікованого D8 `RATIONALIZE`; однак алгоритмічна похідність від ратифікованої арифметики можлива. Правило `derivable does not imply excluded` не дає автоматичної ратифікації.

`scripts/check_d10_bounded_rational.py --self-test` містить незалежний перебір кандидатів з усіма `1≤q≤M`, перевірку алгоритму неперервних дробів, звірку з `Fraction.limit_denominator`, приклади нічий, заборону float та **8 fail-closed мутацій** реєстру.

## Ще інтереси, які слід переносити через доведені закони, а не за назвою хобі

| Наші розмови / проєкти | Кандидат або питання | Рішення |
|---|---|---|
| Аналогове обчислення, `spanda`, E–π, FPGA | `BEST-BOUNDED-RATIONAL` для сигнал → точне раціональне | **Один новий NOT-SELECTED intake**, цей PR |
| Годинники, хронометрія, астрофізичні часові шкали | точні раціональні частоти осциляторів, похибки й добова епоха | HOLD; календар/JD уже в #4887 |
| Музична теорія, акустика, музичні інтервали | відношення двох частот і пошук найкращого малого `p/q` | HOLD, поки не встановлено темперацію й похибку; може бути композицією нашого кандидата |
| SDR / RTL-SDR / BFSK, цифрові сигнали | дискретна енергія тону, фазовий вибір | не дублювати #4887 |
| Маятник AS5600 і ESP32-S3 | `CONTINUOUS-ANGLE-UNWRAP`, невизначеність рівно півоберта | HOLD, уже заявлено суміжну ділянку #4301 |
| VSOP2013, орбіти та астрономія | сферичні координати та астрономічний час | #4887 / #4301; не дублювати |
| Санскрит і граматика Паніні | доказове виведення, контекст, `pratyāhāra` | D7/D10 already harvested; не дублювати `SANDHI-IKO-YAN-ACI`, `RESOLVE-PRATYAHARA` |
| Prolog, CLIPS, Lisp, Advice Taker | унифікація, виведення, керування довірою та provenance | наявні D10 harvest/prove, потрібне перевірене відсікання повторів |
| WSM-OS-Lisp, SIMD, CUDA, Tang FPGA | точна семантика субстрату через oracle parity | ISA/MMIO/ABI **не** коди D10 самі по собі |

Довший математичний горизонт: обчислення `π/e/φ`, продовження дробів, точні межі похибки, синхронізація частот — але ніяких вигаданих постійних нового домену або другорядного текстового коду.

## Доказова межа й координація

- Два **незалежних** арифметичних орієнтири: розрахунок конвергентів і незалежний обмежений перебір (плюс CPython standard library). Це перевірка **закону в Python**, не оракул реального SENS і не proof of mathematical irreducibility.
- До ратифікації: типізований вхід у точну арифметику SENS, жорсткий dedup з D1–D9 та поточними D10 SELECT, перевірка на реальному SENS oracle, аргументований owner-review.
- Усі `coordinate=null`, `ratified=false`. Жодного запозичення Python/Lisp-виконавчих імен у двійкову програму.
- **Не редагувати** канонічні `knowledge/d10-v1-semantic-inventory.json`, `knowledge/d10-fill-v1-state.json` доки інші агенти серіалізовано наповнюють їх через #4885/#4886.
